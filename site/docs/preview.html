Preview and editing

Most files open right in the browser, with nothing to install.

Double-click a file to open it in a tab. To go to the previous or next file of the same folder, press ← or →, or click the arrows at the right of the toolbar. The files come in the order the folder is sorted in, and once the whole folder has loaded, the status bar shows where you are (for example 3 of 12). While you are typing in a file, or the cursor is in a video's controls, the arrow keys keep their usual job there; click outside first.

Text and code files larger than 5 MB, and Word, PowerPoint and Excel files larger than 50 MB, are too large to open in the browser: download them instead.

Most browsers can't show HEIC, TIFF or Photoshop pictures, AVI, MKV, WMV or FLV videos, or WMA and AIFF sound, so these offer a download button instead. The same happens when your browser can't play a particular video or sound file.

Editing Excel workbooks

Open a workbook and click Edit workbook.

  • Type in a cell, or in the formula bar. Start a formula with =.
  • A formula that would have to go through millions of cells one by one, such as COUNTIF over most of a sheet, shows #CALC! instead of slowing the page down. Saving keeps the result Excel stored for it, and Excel calculates it again when it opens the file.
  • Use the toolbar for bold, colours, borders, alignment, number formats and merged cells.
  • Copy and paste works between cells, and to and from Excel on your computer.
  • Insert or delete rows and columns from the Insert and Delete menus. Formulas are adjusted for you.
  • Press Ctrl + Z to undo and Ctrl + S to save. Undo goes back up to 200 steps, of which at most 20 can be row or column inserts and deletes.
  • With a screen reader, move with the arrow keys: the address and value of the cell you move to (or the range you select) are read out.

In a workbook that is only being viewed, screen readers find the cells shown on screen in a table after the sheet. Scroll the sheet with the arrow keys and the table follows.

Saving changes only the cells you edited. Charts, pictures and everything else in the workbook stay as they were.

Workbooks larger than 20 MB can be viewed but not edited online. Download them and use Excel instead.

Editing text files

Text and code files open in an editor with colours for most programming languages. Press Ctrl + S to save.

A file ThirtyFile doesn't recognise, such as Dockerfile, README or a file with an unusual extension, shows Preview isn't available for this file type. If it holds text, click Open in text editor to read and edit it there. This doesn't rename the file or change its type: it is only saved when you save it. Default view goes back; unsaved changes are kept and come back when you open the editor again.

  • You can only save when you may change the file. On a share link, the button shows only when the link allows downloading, and the text is read-only.
  • A file that doesn't look like text (a program, a picture with a strange extension) opens read-only, so saving can't damage it. So does text in an encoding the editor can't write back. UTF-8, UTF-16 and Big5 files are kept as they are, and so are Windows line endings; Big5 is converted to UTF-8 when saved, as the editor says.
  • Files larger than 5 MB don't open in the editor: download them instead.

Markdown

Markdown files open as a formatted page: headings, lists, tables, task lists and code. Switch to Edit above the page to change the text (Source when you may only view the file), and back to Preview to see the result, unsaved changes included.

The page is shown safely: HTML written in the file is not run and can't take on the look of ThirtyFile, links open in a new tab, and only pictures embedded in the file itself are shown. Pictures from other websites are left out, so opening the file doesn't tell those sites about it.

Thumbnails

In the icon views (Large icons, Medium icons and Tiles), pictures, PDFs and videos show a thumbnail. The server makes those of pictures. For PDFs (the first page) and videos (a frame near the start), the first browser of someone who may change the file makes the thumbnail and keeps it on the server, so everyone who can open the file in that space sees it from then on. People who may only view it see one made in their own browser until then. Videos your browser can't play, and PDFs larger than 200 MB, keep their icon. Thumbnails are kept in data/thumbs: those of a file in the content store go when its content is deleted for good, and any thumbnail nobody was shown for 30 days is removed (it is made again when someone looks at the file).

When two people edit the same file

If someone else saved the file while you were editing, your save is stopped and you are told, so nobody's work is overwritten without notice. Copy your changes, reload the file, and add them again.
