First steps

Four things to set up after signing in for the first time. All of them are in the Control panel, at the bottom of the menu on the left.

1. Site address and language

Open Control panel › General.

  • Site URL: the address people use to reach the site, for example https://files.example.com. Share links are built from it, so set it before sharing anything.
  • Default language: English, Traditional Chinese, or the language of each person's browser. In English, dates, times and numbers follow the region set in the browser: for example, a browser set to English (United Kingdom) shows day/month/year and 24-hour times.
  • Personal spaces: whether new users get their own "My files", on which storage location, and how much they may store in it. See Personal spaces.
  • Two-factor sign-in and the minimum password length. See Sign-in security.

2. Where files are kept

Files are kept in the storage folder unless you say otherwise, as ordinary folders: company for "All files", teams/<space name> and users/<user name> (see Where the files are). To use a NAS, S3, SFTP or FTP instead, open Control panel › Storage locations, add the location and make it the default.

See Storage locations for the details of each type.

3. People

Open Control panel › Users to create accounts, and Groups to put people together, for example one group for each department.

If your organisation uses Microsoft, Google or GitHub accounts, or its own identity provider (any OpenID Connect provider, such as Keycloak or Authentik), people can sign in with those. See Single sign-on.

4. Your name and logo

Open Control panel › Branding to set the site name, logo, colours and the picture on the sign-in screen.
