Monitoring

Show how the server is doing in Prometheus and Grafana, with figures that hold no names of people or files.

On this page
  1. Turning it on
  2. In Prometheus
  3. What the figures are
  4. Grafana
  5. What is not in them

Turning it on

Open Control panel › Monitoring. Make a token: it is shown once, and only a fingerprint of it is kept, so copy it now. Then switch on Answer requests for the metrics. The figures are at /metrics on your site, and only a request that sends Authorization: Bearer <token> gets them. Switched off, the address doesn't exist.

You can list the addresses or networks that may ask (203.0.113.7, 10.1.0.0/16); a request from another address is refused before the token is looked at. Without a list, any address may ask with the token. A new token replaces the old one at once. A wrong token counts against the address like a wrong password: after 20 in a row it has to wait. Making and changing the token asks for your password, and is in the activity log.

In Prometheus

Add a scrape job with the token as its credentials:

scrape_configs:
  - job_name: thirtyfile
    scheme: https
    authorization:
      credentials: tfm_…
    static_configs:
      - targets: ["files.example.com"]

An example of alert rules:

groups:
  - name: thirtyfile
    rules:
      - alert: ThirtyFileDown
        expr: up{job="thirtyfile"} == 0
        for: 5m
      - alert: ThirtyFileLocationDown
        expr: thirtyfile_storage_location_up == 0
        for: 5m
      - alert: ThirtyFileDiskNearlyFull
        expr: thirtyfile_disk_free_bytes / thirtyfile_disk_total_bytes < 0.1
        for: 15m
      - alert: ThirtyFileBackupOverdue
        expr: thirtyfile_backup_last_complete_age_seconds > 2 * 86400
      - alert: ThirtyFileBackgroundLoopStuck
        expr: time() - thirtyfile_background_last_success_timestamp_seconds{job="maintenance"} > 3 * 3600
      - alert: ThirtyFileCertificateEnds
        expr: thirtyfile_ftps_certificate_expiry_seconds < 14 * 86400

Grafana

Import thirtyfile-grafana.json (Dashboards › New › Import) and choose your Prometheus. It shows requests and how long they take, sign-ins, storage operations, disks, tasks, backups and what is firing.

What is not in them

No name of a person or a file, no address of a visitor and no path: labels are fixed words (a method, a kind of task, a kind of event), and the names of the storage locations and backup policies that administrators chose. A name of a location or a policy that holds a quote or a line break is written as the format asks.

The counters start again at zero when the server restarts, as Prometheus expects (rate() and increase() deal with it). The figures that have to be looked up (sessions, accounts, disks, the database, backups) are looked at every 15 seconds while monitoring is on, and are kept in memory: a request for the metrics takes no lock and reads no disk, so asking often costs nothing. The memory, open files and threads are shown on Linux only.
