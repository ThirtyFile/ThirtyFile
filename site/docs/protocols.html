SFTP, S3 and FTP

Programs can work with ThirtyFile's files over standard protocols. SFTP is available when an administrator enables it. S3 buckets and FTP receive folders are separate features; their availability is described below.

Which one to use

Use WebDAV to map your spaces as a drive. Use SFTP for encrypted file transfers with WinSCP, FileZilla, Cyberduck, OpenSSH or rclone. SFTP shows the same tree and follows the same permissions as WebDAV.

SFTP

Under Control panel › General › Apps and protocols, turn on Allow SFTP access. It is off by default. The port is set at startup with THIRTYFILE_SFTP_ADDR (default 0.0.0.0:2022). Publish it separately in Docker Compose; it does not go through an HTTP reverse proxy.

services:
  thirtyfile:
    environment:
      THIRTYFILE_SFTP_ADDR: 0.0.0.0:2022
    ports:
      - "8080:8080"
      - "2022:2022"

Add these entries to your existing Compose service, keeping its image and volumes. Restart with docker compose up -d. Open the chosen TCP port in the firewall only where it is needed.

Connecting

Choose SFTP in your client, your server hostname, port 2022, your ThirtyFile username and an app password. Your account password does not work here. A read-only app password cannot change files, even for an administrator. Check the host key fingerprint shown in the control panel before trusting the first connection.

sftp -P 2022 amy@files.example.com
# After connecting:
ls
cd "My files"
put report.csv
get report.csv

SSH public keys

An administrator also enables Allow SSH keys. Under Account menu › SFTP keys, add a name and your SSH public key. Confirm your current password and two-factor code when requested. Keep the private key on your device. The dialog shows the fingerprint and last use; removing a key stops its access, including existing sessions.

sftp -i ~/.ssh/id_ed25519 -P 2022 amy@files.example.com

What SFTP supports

ThirtyFile roles and sharing control access. Unix owner changes and permission changes such as chmod 600 are rejected; modes supplied when creating an item are advisory. With rclone, set disable_hashcheck = true, because shell commands for remote checksums are unavailable. Ask your administrator for the expected host key fingerprint if you cannot access the control panel.

List and download files, upload, resume at an offset, make folders, rename, move, and remove items (to the trash). Writes are staged and committed when the file closes: quotas, upload limits, versions and activity records apply. A disconnected unfinished write is discarded. Times sent by clients are accepted but ignored. There is no shell, command execution, rsync over SSH, forwarding or symbolic links. Each account may have five sessions, with 32 open handles per session and a five-minute idle timeout.

The server generates an ed25519 host key in the data folder on first start. Keep it in data backups. Replacing it changes the fingerprint and clients should ask you to verify the change.

S3 buckets

Publishing a folder as a bucket with its own Access Keys is a separate feature under development. It does not use your SFTP app password. Connecting ThirtyFile to an existing S3 storage location is already described in Storage locations.

FTP receive folders

An FTP receive server is not available. It is planned only for a concrete need from a scanner or camera that cannot use SFTP. An existing FTP server can be added as a storage location; that is a different feature.

Examples

A server can upload a nightly report with an SSH key and an SFTP script. A designer can transfer a large project with Cyberduck. For rclone, run rclone config, choose SFTP, set the hostname and port, verify the host key, and use an app password or SSH private key; avoid putting credentials in command history.
