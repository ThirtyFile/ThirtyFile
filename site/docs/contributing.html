Contributing

How to report a problem, suggest an idea, or change the code of ThirtyFile.

Problems and ideas

  • Open an issue and pick Report a problem or Suggest an idea. The form asks for what is needed to help you.
  • Look through the existing issues first. If yours is there, add to it instead of opening a new one.
Security problems are reported privately. Use Report a vulnerability, not an issue, so the problem can be fixed before it is public.

Changing the code

Nothing is pushed to main directly. Every change is a pull request from its own branch.

  1. Start from an issue. For anything larger than a small fix, agree on the idea there first.
  2. Create a branch from main, named after what it does:
    BranchFor
    feat/share-link-editingSomething new
    fix/upload-resumeA repair
    docs/backup-guideThe website and guides
    chore/update-actionsTools, builds and dependencies
  3. Make the change, and run the checks below.
  4. Open a pull request. Give it a title that says what changes in plain words, and one label. Write Closes #123 in the description to close the issue when it is merged.
  5. Wait for the checks. The tests and the image build must pass before it can be merged.
  6. Merge. The pull request becomes one commit on main, and its branch is deleted.

Checks

Run these before opening a pull request. The same checks run on GitHub.

cd server && cargo test && cargo clippy --all-targets
cd ../web && pnpm typecheck && node scripts/check-i18n.mjs
  • Code, comments and guides are written in English.
  • Text in the interface is written in English in the code, with its Traditional Chinese translation in web/src/lib/i18n/zh-TW/.
  • When behaviour changes, update the guide that describes it, in site/docs/.

A change that only touches the website or the guides skips the tests and the image build.

Releases

What is on main is published as the edge image after every merge. A release is made by tagging a version:

git switch main && git pull
git tag v1.2.3
git push origin v1.2.3

The tag builds the images 1.2.3, 1.2 and latest, and creates the release on GitHub with notes put together from the merged pull requests.

NumberGoes up when
