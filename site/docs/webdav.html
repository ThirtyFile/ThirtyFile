Mapping it as a drive (WebDAV)

Open your ThirtyFile spaces in Windows File Explorer, macOS Finder, the Files app of your phone or rclone, as if they were a drive on your computer.

The address and signing in

ThirtyFile speaks WebDAV at /dav/ on its own address, for example:

https://files.example.com/dav/

Sign in with your username and an app password, never your own password. Create one for each computer or phone under App passwords in the account menu:

  • Choose Read and change files to work with your files. A read-only app password can open and download files but can't save, create, rename, move or delete anything.
  • Accounts that sign in with single sign-on use an app password here too.
  • Two-factor sign-in doesn't ask for a code here. Wrong app passwords count towards the usual limit: after 30 from one address, that address has to wait 15 minutes.

What you see

The top folder holds one folder per space you can use:

  • My files, your personal space, if you have one.
  • The company space (All files, unless your administrator renamed it) and your team spaces, by their names. If two have the same name, the later one gets a number, such as Projects (2).
  • Shared with me: folders and files other people shared with you from spaces you aren't a member of.

These are the same paths the address bar shows in the browser, where you can also type or paste them (see Paths).

Everything works as it does in the browser: what you may change depends on your permissions, read-only spaces can't be changed, the space's storage limit and the upload size limit apply, and every change shows in the activity log. Deleting a file or folder moves it to the trash, where you can restore it in the browser.

Windows

  1. In File Explorer, right-click This PC and choose Map network drive (on Windows 11, it's under … (See more) in the toolbar).
  2. Pick a drive letter and enter the address in Folder: https://files.example.com/dav/
  3. Tick Connect using different credentials, choose Finish, and enter your username and the app password. Tick Remember my credentials to connect again after a restart.
Windows only sends passwords over HTTPS. ThirtyFile needs to be behind HTTPS with a certificate Windows trusts; a plain http:// address is refused unless the registry value BasicAuthLevel of the WebClient service is changed, which isn't recommended. Windows also limits files to 50 MB by default (FileSizeLimitInBytes, under HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters; the largest value is 4 GB).

macOS

  1. In Finder, choose Go › Connect to Server (⌘ K).
  2. Enter https://files.example.com/dav/ and choose Connect.
  3. Choose Registered User and enter your username and the app password. Tick Remember this password in my keychain if you like.

The spaces appear as a drive in the Finder sidebar under Locations. Finder saves hidden files starting with ._ next to files with extra information; they appear in the browser too, and can be deleted.

iPhone, iPad and Android

  • iPhone and iPad: in the Files app, tap … at the top of Browse, choose Connect to Server, enter https://files.example.com/dav/, then choose Registered User with your username and the app password.
  • Android has no WebDAV built in: use a file manager app that supports WebDAV (for example Material Files, Solid Explorer or CX File Explorer), add a WebDAV connection with the address, your username and the app password.

rclone

rclone copies and syncs files with ThirtyFile from the command line, for example for backups. Set it up once (it asks for the app password and stores it scrambled):

rclone config create thirtyfile webdav url=https://files.example.com/dav/ vendor=other user=amy pass=tfa_… --obscure

Then use it like any other rclone remote:

rclone ls "thirtyfile:My files"
rclone copy ~/Pictures "thirtyfile:My files/Pictures" --progress
rclone mount thirtyfile: ~/ThirtyFile --vfs-cache-mode writes

A read-only app password is enough for rclone copy from ThirtyFile, for example to back your files up to another place.

Good to know

  • Each file is sent in one piece. When ThirtyFile is behind a reverse proxy, the proxy must let large requests through: see Putting it on the internet.
  • Names follow the same rules as in the browser: characters Windows doesn't allow in names (\ / : * ? " < > |) are refused.
  • Office and other programs lock files while they are open. ThirtyFile answers these locks so that saving works, but doesn't enforce them: when two people save the same file at the same time, the last one wins. Use the browser's online editor for working on a file together.
  • Folders on the server (folder spaces) work too: changes are made in the folder itself, and files added on the server show up when the folder is opened.
  • Moving or copying a large folder to or from a folder on the server copies its files. ThirtyFile answers when that is done; when it takes more than a minute, it answers that the change was accepted and finishes it in the background, even if the program gives up waiting or loses its connection. Look again a little later to see the result.
  • Moving an item that was shared with you to one of your own spaces isn't allowed, as in the browser; copy it instead.
  • Each folder is listed one level at a time; a client that asks for a whole tree at once is told to ask folder by folder, which all common clients do.
