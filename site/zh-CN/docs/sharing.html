与同事共享

右键点击文件夹或文件，选择共享给…。输入用户名或用户组，选择允许的操作，可选填访问权限结束日期，再点击添加。如果你自己的访问权限有到期日，就不能给自己、自己所属用户组或所有人授予更长的权限。

项目会出现在对方菜单的与我共享中，并通过铃铛通知（已配置邮件时也会发送邮件）：参阅通知。

角色

角色可执行的操作
查看者浏览、预览和下载
投稿者还可添加文件和文件夹，但只能更改、移动或删除自己添加的项目，且须账号获准执行。上传的文件与别人的文件同名时，两者都保留。服务器文件夹中找到的项目算是别人的；自己创建的文件夹里有别人的项目时，就无法移动或删除。不能创建分享链接，也不能管理成员
编辑者还可上传、编辑、删除和创建分享链接，但每项操作仍须账号获准执行（控制面板 › 用户），且分享链接只能在允许编辑者创建链接的空间中创建（谁可以创建链接）
管理者账号获准分享时，还可管理成员与共享权限
所有者账号获准删除时，还可删除空间

受限文件夹

将人事或合同资料保留在部门原本的目录中，同时只开放给少数人。空间所有者打开文件夹的与他人共享…对话框，选择限制文件夹。界面会列出将停止继承的授权，并要求确认。现有文件夹在你主动设置前维持原本权限。

  • 上层授权在受限文件夹停止。本文件夹及下层的直接授权仍有效，直到遇到另一个受限文件夹。直接共享的下层项目会出现在与我共享，不显示用户无权打开的上层名称。
  • 受限文件夹在文件列表与文件夹树中，名称后方会显示锁形图标，属性中也会注明。
  • 空间所有者保留访问权限。管理员在团队及公司空间中保留访问权限，他人的个人空间仍维持隐私。空间管理者需要在受限文件夹或下层获得明确授权。只有空间所有者及上述管理员能开关限制。
  • 列表、搜索、标签、最近使用、收藏、历史、通知及回收站会排除无权访问的名称、内容、大小与记录。可见使用量不包含无权访问的文件，实际空间配额仍计入所有存储内容。WebDAV 与 SFTP 遵守相同权限。
  • 同一个文件夹中的名称不能重复，看不到的也算：创建或改名成看不到的受限文件夹的名称时会被拒绝，或自动加上编号。因此可以用这种方式确认某个名称存在，但看不到文件夹的内容；若名称本身也很敏感，请为受限文件夹取普通的名称。
  • 下载上层文件夹的 ZIP 时只包含可见项目。复制、压缩、移动或删除整个上层文件夹，若会带走无权访问或更改的下层项目，操作会被拒绝。移动受限文件夹会保留限制；复制会保留限制，但不复制成员授权。一般下层项目移出后会继承目标位置的授权。
  • 在文件夹空间中，受限文件夹若在服务器的磁盘上被移动，下次扫描以相同名称和创建时间找到它时，会保留限制和授权；找不到时，空间的扫描报告会列出它，由所有者在新的位置重新设置限制。
  • 从上层发布的分享链接、S3 存储桶或 FTP 接收范围都不能穿过限制，即使创建者是所有者或管理员。要明确开放该范围，请直接发布受限文件夹本身；其中更深层的受限文件夹仍不包含在内。

确认对象后，选择恢复继承授权即可再次应用上层授权。空间根目录与回收站内的文件夹不能开关限制。上传或其他待完成更改在最后保存时会再检查权限。旧项目无法再确认可见范围时，其历史名称会保守保护；所有者及管理员仍可读取其有权查看的管理记录。

通过链接分享

右键点击项目，选择创建分享链接，或选中后点击工具栏的创建分享链接。除非另作设置，持有链接的任何人都无需账号即可查看和下载。

  • 到期时间：链接在 1、7、30 或 90 天后失效，也可设为永不过期。
  • 密码：访客必须先输入密码才能查看，一天后需重新输入。密码长度须满足账号密码的要求（控制面板 › 常规）。同一链接密码错误十次后，每次重试都需等待更长时间，不论来源地址。请将密码与链接分开发送。输入时密码会隐藏，点旁边的眼睛按钮即可显示。
  • 下载次数上限：达到次数后链接失效。恢复下载或在视频中跳转只计为一次；文件夹内每个文件分别计数。
  • 访客可以：决定是否允许下载，以及文件夹是否允许上传文件。详见下文。

点击链接旁的编辑链接可修改密码、到期时间、下载次数上限或访客权限，地址保持不变。设置新密码后，之前打开过链接的人也必须输入新密码。

通过链接接收文件

如果要收集文件，例如向客户收件，创建文件夹链接并勾选上传文件。访客会看到上传按钮，也可将文件拖入文件夹。

  • 同时勾选只能上传时，访客看不到文件夹内容，也无法下载，只会看到向该文件夹发送文件的区域。拖入文件夹时会上传其中的文件；名称已存在时，以新名称保存，不向访客透露冲突。
  • 上传的文件归你所有，计入空间容量，遵守常规命名规则和上传大小限制。重名文件会加上数字，例如 report (1).pdf。
  • 每次上传会以你的名字和通过分享链接标注在活动日志中，也记录在链接访问日志。收到文件时会通知你（参阅通知）。
  • 只有你仍可修改文件夹时，链接上传才有效。失去权限，或文件夹移出原共享文件夹后，链接上传会停止。
  • 同一链接尚未完成的上传同时最多占用 20 GB。通过链接上传的任务一天未收到数据后会被丢弃，访客需重新发送该文件。
  • 未完成的上传只能从开始上传的浏览器继续。同一链接的其他访客看不到、无法继续，也无法取消。

仅供查看的链接

取消勾选下载后，访客只能预览文件：下载按钮和 ZIP 下载选项会消失，服务器也会拒绝通过该链接下载。

这只能增加保存难度，并非保护措施。为了显示预览，完整文件仍会发送到访客浏览器；有意保存的人可以从浏览器保存或截图。不要依赖此设置保护不得流出公司的文件。

你的链接

菜单中的我的分享链接列出你创建的所有链接、到期时间和使用次数。选中链接可复制、编辑或删除；删除链接会立即使其失效。位置列显示每个链接项目所在的空间和上层文件夹（我的文件/ABC），名称相同的文件夹因此分得出来；点一下可打开该文件夹。在有受限文件夹的空间中，路径从你看不到的文件夹之下开始。点列标题可按该列排序，再点一次反向；排序方式会被记住。

将列表切换为所有我可管理的链接，还可看到别人在你管理的空间、或你拥有的文件上创建的链接。你也能编辑、删除这些链接，并查看谁打开过它们。项目的分享对话框和详细信息窗格显示同样的链接。

谁可以创建链接：团队空间和全部文件由空间的管理者在成员对话框底部选择，可选编辑者、管理者和所有者（默认）、只有管理者和所有者，或没有人。成员仍可用共享给…把项目分享给其他人。由这个设置不再允许的人创建的链接会失效，改回原来的设置后就会恢复；更改前对话框会先告诉你有几个。在我的文件中，一律由你自己决定。

创建者失去项目访问权限或分享权限（例如离开团队空间），或空间不再允许他创建链接，或账号被禁用后，链接也会失效。删除账号会删除该账号创建的链接。

管理员设置

控制面板 › 所有分享链接列出所有空间的公开链接和创建者。可按空间、创建者、有效状态筛选，然后编辑、删除或打开访问日志。其他人个人空间中的链接只能删除，不显示链接地址和项目（参阅管理员能看到什么）。

在控制面板 › 常规 › 分享链接中设置规则：

  • 允许公开分享链接：关闭后无人可创建链接，现有链接全部停止工作，直到重新开启。链接不会删除。
  • 要求密码：新链接必须设置密码，已有密码也不能移除。
  • 最长有效期：新增或修改的链接必须在指定天数内到期。

后两项规则只适用于之后新增或修改的链接。之前创建的链接保持原状；请在所有分享链接中找出并编辑或删除。

空间

空间是具有独立成员和容量限制的驱动器。

  • 我的文件：个人空间，除非主动共享其中项目，否则只有你能看到。
  • 全部文件：公司共用空间，管理员可以修改名称。
  • 团队空间：用于部门或项目，管理者可添加和移除成员。

文件夹也可发布为 S3 存储桶，供程序访问。管理员或 S3 设置允许的空间管理者可创建文件夹专用密钥。个人空间和不允许任何人创建分享链接的空间不能发布。

扫描仪等设备可使用FTP 接收文件夹和只显示一次的专用设备密码。管理员和获准的空间管理者可管理权限与到期日；访客账号和个人空间无法发布。默认禁止列出内容和下载。停用或删除凭据不会删除文件。

访客权限与共享策略

在控制面板 › 常规 › 访客访问与共享设置授予访客的最长天数，默认为 90 天。新增或更新对访客的直接授权，或对包含访客的群组授权，都必须设置期限内的到期日，管理员也不例外。若到期日只超出上限一小时以内（例如电脑时钟稍快），会改为最长期限。角色只能选择编辑者、贡献者或查看者。修改设置不会重写现有到期日。权限到期后，浏览器、WebDAV 与 SFTP 的访问都会停止。

只能在自己的群组内共享限制新增或更新的授权：对方必须与你同属至少一个当前群组，目标群组也必须包含你。选择列表会遵守此策略，管理员不受此限制。现有对其他人的授权会保留；若要停止，请明确移除。此设置管理账号与群组访问，不会改动现有公开链接。
