单人模式

把 ThirtyFile 当作沙盒里给一个人用的文件管理器：无需登录、没有账号，只管理一个文件夹。

有哪些不同

单人模式适合只有你能访问的地方：沙盒、虚拟机，或在自己电脑上运行的容器。打开网页，文件就在眼前。它默认关闭，必须明确开启，并且不影响普通服务器。

  • 无需登录。访问网页的人都是同一个人。没有账号、密码或两步验证码。
  • 一个文件夹。文件就是你选的文件夹（THIRTYFILE_FILES）里的普通文件。可以浏览、上传、下载、创建、编辑、重命名、移动和删除，预览、搜索、标签、回收站和编辑器都和平时一样。在文件夹外面做的更改也会显示出来。
  • 多人才需要的功能都没有。用户和群组、权限、分享链接、访客、控制面板、通知、WebDAV、S3 存储桶和 FTP 接收文件夹不只是隐藏，而是直接关闭：服务器不会响应它们。SFTP 也保持关闭。
  • 只动那个文件夹。服务器只在该文件夹内读写。文件夹内指向外面的链接会被跳过，和所有文件夹空间一样。

用 Docker 运行

docker run -d --name thirtyfile --restart unless-stopped \
  -p 127.0.0.1:8080:8080 \
  -v /srv/thirtyfile/data:/data \
  -v /srv/work:/files \
  -e THIRTYFILE_SINGLE_USER=true \
  -e THIRTYFILE_FILES=/files \
  -e THIRTYFILE_RUN_AS=1000:1000 \
  ghcr.io/thirtyfile/thirtyfile:latest
部分作用
-p 127.0.0.1:8080:8080只在这台电脑上开放网页。少了 127.0.0.1:，Docker 会绕过防火墙，把端口开放给电脑所在的每个网络
-v /srv/work:/files要管理的文件夹。请挂载沙盒内的某个文件夹，不要挂载更大的范围：服务器能动到的就只有它
THIRTYFILE_SINGLE_USER=true开启单人模式
THIRTYFILE_FILES=/files文件夹在容器内的路径。必填
THIRTYFILE_RUN_AS=1000:1000服务器使用的用户。它必须能修改 /files 内的文件：请使用该文件夹所有者的编号（id -u 和 id -g）

/data 文件夹保存索引、缩略图和设置。它不能位于文件文件夹里面，而且只属于这个模式：在单人模式创建的数据文件夹无法启动普通服务器，反过来也一样。之后改选别的文件夹，就会改为显示那个文件夹；旧的文件夹保持原样。

从你的电脑访问

在容器内，服务器监听所有地址，而 Docker 只会转发你发布的端口。使用 -p 127.0.0.1:8080:8080 时，在运行 Docker 的电脑上打开 http://localhost:8080。不用 Docker 时，服务器默认只监听 127.0.0.1:8080（可用 THIRTYFILE_ADDR 更改）。

当沙盒是另一台机器或虚拟机时，从你的电脑转发端口，网页到达时仍然是 localhost：

ssh -L 8080:127.0.0.1:8080 user@sandbox

然后在你的电脑上打开 http://localhost:8080。许多沙盒和开发容器有端口转发设置，效果相同。

服务器只响应 localhost、127.0.0.1 和 [::1]。用其他名称访问的网页会看到“unknown host name”。当转发工具或代理为网页取了自己的名称，请把它列出来：

-e THIRTYFILE_ALLOWED_HOSTS=sandbox.example.com

谁能访问它

这里没有登录，所以只要能访问端口，就能拿到文件夹内的所有文件。挡住其他人的是沙盒和周围的网络，而不是 ThirtyFile。请让端口只在本机地址上，或放在你自己的转发后面，不要发布到其他网络或互联网。启动时，如果监听的地址不是本机地址，ThirtyFile 会在日志中写下警告；在 Docker 内这是正常的，重要的是发布出去的端口。

因为你浏览的网站可以向 localhost 发送请求，ThirtyFile 仍然会做这些事：

  • 浏览器表示来自其他网站的请求会被拒绝，Origin 不是网页本身的更改也一样。
  • 使用不是这台电脑名称的请求会被拒绝，这能挡住让自己的名称指向你电脑的网站（DNS 重新绑定）。
  • 只能访问所选文件夹之下的文件。

同一台电脑上的程序仍然可以使用该端口。如果电脑上有不信任的程序，请把沙盒的网络与它们隔离。

设置

变量默认值作用
THIRTYFILE_SINGLE_USERfalse开启单人模式
THIRTYFILE_FILES要管理的文件夹的完整路径。此模式必填，且不能包含数据文件夹或位于其中
THIRTYFILE_ADDR127.0.0.1:8080服务器监听的地址（普通服务器是 0.0.0.0:8080；Docker 镜像自己会设置）
THIRTYFILE_ALLOWED_HOSTS除了 localhost 之外，网页可以使用的名称，以逗号分隔

其他设置，例如 THIRTYFILE_TRASH_DAYS 和 THIRTYFILE_MAX_UPLOAD_MB，和设置中的说明相同。备份、存储位置等是控制面板的功能，这里没有：请直接复制文件夹，或使用沙盒本身的快照。

改回普通服务器

用新的数据文件夹启动普通服务器，再把该文件夹添加为空间。你的文件从来不在数据文件夹里，所以不需要导出。
