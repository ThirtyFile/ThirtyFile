日志

打开控制面板 › 活动日志。

日志记录内容
活动上传、编辑、迁移、删除、分享和设置变更
分享链接访问谁打开了链接、密码尝试、预览和下载
登录成功与失败的登录、退出登录（包括从设备中让设备退出）、修改密码、两步验证（错误验证码、使用恢复码、开启、关闭或重置），以及应用密码的创建、移除和错误密码尝试
错误用户遇到的错误：服务器无法完成的请求，以及网页发生的错误（页面异常，上传、预览或文件操作失败）

可按人员、操作和日期筛选，并将结果导出为 Excel 能打开的 CSV 文件。导出文件使用页面中看到的名称、语言和你的时区。

管理员可以查看活动日志；空间管理者可从空间属性（此电脑）查看对应空间的日志。其他人可以在可访问文件或文件夹的详细信息窗格查看近期活动。

其他人的个人空间记录会说明谁在何时做了什么，但不显示具体文件或文件夹：项目名称和详情会省略（参阅管理员能看到什么）。搜索、CSV 导出、个人空间分享链接的访问日志，以及归档文件也遵守相同规则。

所有人都可以从账号菜单查看自己的登录历史和已登录设备。参阅你的账号。

错误

错误标签页仅供管理员使用。每条记录显示发生时间、遇到错误的人（或未登录）、来源和当时的操作。点击时间可查看详情：错误类型、请求状态、请求 ID、版本，以及网页错误的调用堆栈。

  • 服务器记录表示服务器返回错误的请求。意外失败（数据库或存储问题、请求耗时过长）属于错误；被拒绝的更改（名称已存在、没有权限、文件过大）属于警告。可按严重程度筛选。
  • 网页记录由页面发送：页面异常、未捕获的脚本错误，以及上传、预览、保存和文件操作时显示的失败。
  • 网页报告服务器已记录的失败请求时，两者会通过请求 ID 合并为一条记录，网页显示的内容列在网页报告下。
  • 10 分钟内再次出现相同错误时，只增加原记录的次数，不新增记录。报告还按人员和分钟限流，避免循环报错的网页填满日志。
  • 文件与文件夹名称不会记录：引号中的文字替换为 "…"（或 「…」）；网页报告服务器的英文消息，而非译文；请求按路由记录（PATCH /api/nodes/{id}），不会记录实际请求的路径。密码、cookie、分享链接令牌和文件内容永远不会记录。完整服务器故障信息可在服务器日志（docker logs）中用同一请求 ID 找到。

日志保留时间

在控制面板 › 日志设置中：

  • 活动和分享链接访问记录保留 180 天，登录记录保留 365 天。错误记录与活动记录保留相同时间。
  • 较旧记录移入压缩归档文件，保留 3 年，可从同一页面下载。归档每行包含一条 JSON 记录，使用日志内部代码（upload、bad_password），时间为自 1970 年起的秒数（UTC），不因显示语言改变。
  • 可关闭访客 IP 地址和浏览器的记录。
日志包含 IP 地址，在许多国家属于个人数据。请按照自己的隐私政策保留和删除。

品牌

打开控制面板 › 品牌。

  • 名称与标志，可为深色模式另设一个标志。标志也用作浏览器标签页图标。
  • 浅色和深色模式的颜色。
  • 外观：浅色、深色或跟随个人设备，以及是否允许用户自行更改。
  • 登录界面：背景图片、文字，以及是否显示锁屏界面。
