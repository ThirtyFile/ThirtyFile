初始设置

首次登录后需要设置的四件事。它们都在控制面板中，位于左侧菜单的最下方。

安装和初始设置这两篇指南有简体中文版，其他指南目前只有英文版。

1. 网站地址和语言

打开控制面板 › 常规。

  • 网站地址：大家访问网站所用的地址，例如 https://files.example.com。分享链接基于它生成，所以请在分享任何内容之前先设置好。
  • 默认语言：没有在账号菜单中选择语言的人使用的语言：英文、繁体中文、简体中文、日文，或按每个人的浏览器语言（浏览器语言中第一个 ThirtyFile 提供的语言）。已登录的人使用默认语言，而不是浏览器语言；未登录的访客（例如打开分享链接的人）使用浏览器语言，只有当 ThirtyFile 不提供其浏览器的任何语言时，才使用默认语言。ThirtyFile 在各人空间中创建的项目（例如“Files of amy”文件夹）也以默认语言命名（默认语言跟随浏览器时则用英文）。使用英文时，日期、时间和数字会按浏览器设置的地区显示：例如浏览器设为英语（英国）时，会显示“日/月/年”和 24 小时制时间。
  • 个人空间：新用户是否拥有自己的“我的文件”、放在哪个存储位置，以及最多可以存放多少数据。请参阅个人空间。
  • 两步验证和密码最短长度。请参阅登录安全。

2. 文件存放在哪里

除非另行指定，文件会以普通文件夹的形式存放在 storage 文件夹中：“全部文件”在 company，其他则在 teams/<空间名称> 和 users/<用户名>（请参阅文件存放在哪里）。如需改用 NAS、S3、SFTP 或 FTP，请打开控制面板 › 存储位置，添加位置并设为默认。

各种类型的详细信息，请参阅存储位置。

3. 人员

在控制面板 › 用户中创建账号，在用户组中把人员分组，例如每个部门一个用户组。

如果你的组织使用 Microsoft、Google 或 GitHub 账号，或有自己的身份提供商（任何 OpenID Connect 服务，例如 Keycloak 或 Authentik），大家就可以用这些账号登录。请参阅单点登录。

4. 你的名称和标志

在控制面板 › 品牌中设置网站名称、标志、颜色，以及登录界面上的图片。
