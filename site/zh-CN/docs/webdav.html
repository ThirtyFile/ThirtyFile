映射为网络驱动器（WebDAV）

通过 Windows 文件资源管理器、macOS Finder、兼容 WebDAV 的手机应用或 rclone 打开 ThirtyFile 空间，就像使用电脑上的驱动器一样。

地址与登录

ThirtyFile 在自身地址的 /dav/ 路径提供 WebDAV，例如：

https://files.example.com/dav/

请使用用户名和应用密码登录，不要使用账号登录密码。在账号菜单的应用密码中，为每台电脑或手机分别创建一个：

  • 如需处理文件，选择读取并更改文件。只读应用密码可打开和下载文件，但不能保存、创建、重命名、移动或删除任何项目。
  • 通过单点登录访问的账号在这里也使用应用密码。
  • 这里不会要求两步验证码。错误应用密码会计入常规限制：同一地址失败 30 次后，该地址必须等待 15 分钟。

目录内容

顶层目录为每个可访问空间提供一个文件夹：

  • 我的文件：你的个人空间（如果有）。
  • 公司空间（除非管理员改名，否则为全部文件），以及按名称显示的团队空间。两个空间同名时，后一个会加上数字，例如 Projects (2)。
  • 与我共享：别人从你不是成员的空间中向你共享的文件夹与文件。

这些路径与浏览器地址栏显示的相同，也可以在浏览器中输入或粘贴（参阅路径）。

所有行为与浏览器一致：能否更改取决于权限，只读空间不能修改，空间存储上限和上传大小限制同样适用，每次更改都会出现在活动日志中。删除文件或文件夹会移入回收站，可在浏览器中还原。

Windows

Windows 内置客户端需要 WebClient 服务。Microsoft 已弃用该服务，默认不启动；是否可用取决于 Windows 安装和管理员策略。无法映射驱动器时，请使用专用 WebDAV 客户端或 rclone。参阅 Microsoft 的 WebClient 公告。

  1. 在文件资源管理器中右键点击此电脑，选择映射网络驱动器（Windows 11 中位于工具栏的 …（查看更多））。
  2. 选择驱动器盘符，在文件夹中填写地址：https://files.example.com/dav/
  3. 勾选使用其他凭据连接，点击完成，输入用户名和应用密码。勾选记住我的凭据即可在重启后重新连接。
Windows 只通过 HTTPS 发送密码。ThirtyFile 需要通过 HTTPS 提供服务，并使用 Windows 信任的证书；普通 http:// 地址会被拒绝，除非修改 WebClient 服务的注册表值 BasicAuthLevel，但不建议这样做。Windows 默认还限制文件大小为 50 MB（位于 HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters 的 FileSizeLimitInBytes，最大值为 4 GB）。

macOS

  1. 在 Finder 中选择前往 › 连接服务器（⌘ K）。
  2. 输入 https://files.example.com/dav/，点击连接。
  3. 选择注册用户，输入用户名和应用密码。可以勾选在我的钥匙串中记住此密码。

空间会作为驱动器显示在 Finder 侧边栏的位置下。Finder 会在带有额外信息的文件旁创建以 ._ 开头的隐藏文件；这些文件也会显示在浏览器中，可以删除。

iPhone、iPad 与 Android

  • iPhone 与 iPad：使用明确支持通过 HTTPS 访问 WebDAV 的应用，在应用中添加地址、用户名和应用密码。如果应用提供“文件”扩展，可在“文件”应用中启用，然后浏览该连接。“文件”内置的连接服务器用于 SMB 服务器，不能直接连接 ThirtyFile 的 /dav/ 端点。Apple 的“文件”功能说明介绍了 SMB 支持。
  • Android：使用明确支持 HTTPS WebDAV 的文件管理器或客户端，添加地址、用户名和应用密码。仅支持 SMB、FTP 或 SFTP 不代表该应用是 WebDAV 客户端。

rclone

rclone 可通过命令行与 ThirtyFile 复制和同步文件，例如用于备份。请使用交互式配置，避免应用密码被写入 shell 历史：

rclone config

创建名为 thirtyfile 的 remote，选择 webdav，URL 设为 https://files.example.com/dav/，vendor 选择 other，然后按提示输入 ThirtyFile 用户名和应用密码。采用此用户名/密码方式时，bearer token 留空。rclone 会混淆保存的密码，但这种混淆可以逆向还原：请像保护凭据一样保护配置文件。

然后可以像其他 rclone remote 一样使用：

rclone ls "thirtyfile:My files"
rclone copy ~/Pictures "thirtyfile:My files/Pictures" --progress
rclone mount thirtyfile: ~/ThirtyFile --vfs-cache-mode writes

使用 rclone copy 从 ThirtyFile 复制文件时，只读应用密码就足够，例如将文件备份到其他位置。

连接或保存失败时

  • 401 或不断要求输入密码：使用用户名和应用密码，不要使用浏览器登录密码、邮箱地址或两步验证码。检查应用密码是否过期或被撤销，以及账号是否启用。失败次数过多后，请等待 15 分钟再尝试。
  • 能读取但不能保存：检查应用密码的写入权限、空间中的权限、存储上限，以及存储位置是否只读或离线。
  • 404、登录网页或意外重定向：使用完整的 /dav/ 地址，并配置反向代理转发 WebDAV 方法和 Authorization 请求头。HTML 登录页不是 WebDAV 响应。
  • 证书或大文件错误：使用 HTTPS 和受信任证书。同时检查客户端传输限制、代理请求大小限制和超时设置。浏览器上传使用分块，WebDAV 则通过单次请求发送完整文件。

注意事项

  • 每个文件一次完整发送。ThirtyFile 位于反向代理后方时，代理必须允许大请求通过：参阅通过互联网访问。
  • 名称规则与浏览器相同：Windows 不允许的字符（\ / : * ? " < > |）会被拒绝。
  • Office 等程序在打开文件时会加锁。ThirtyFile 会响应这些锁请求以便保存，但不会强制执行锁：两人同时保存同一文件时，最后保存者的内容生效。共同处理文件时请使用浏览器中的在线编辑器。
  • 服务器文件夹（文件夹空间）也可使用：更改直接写入文件夹本身，服务器新增的文件会在打开文件夹时显示。
  • 将大文件夹移入或移出服务器文件夹时，需要复制其中的文件。ThirtyFile 在完成后响应；如果超过一分钟，会响应已接受更改并继续在后台完成，即使客户端已停止等待或断开连接。稍后重新查看即可确认结果。
  • 与浏览器一样，不能将别人共享给你的项目移动到自己的空间；请改用复制。
  • 每次只列出文件夹的一层；请求一次列出整棵目录树的客户端会收到逐文件夹查询的要求，常见客户端都采用这种方式。
