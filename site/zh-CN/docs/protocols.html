SFTP、S3 和 FTP

程序可通过标准协议操作 ThirtyFile 文件。管理员启用后即可使用 SFTP。S3 存储桶和 FTP 接收文件夹是独立功能，提供状态如下说明。

如何选择

使用 WebDAV 将空间挂载为磁盘；使用 SFTP 通过 WinSCP、FileZilla、Cyberduck、OpenSSH 或 rclone 进行加密传输。SFTP 显示与 WebDAV 相同的目录树，遵循相同权限。

SFTP

在控制台 › 常规 › 应用程序与协议开启允许 SFTP 访问，默认关闭。启动时使用 THIRTYFILE_SFTP_ADDR 设置端口（默认 0.0.0.0:2022）。在 Docker Compose 单独发布端口，SFTP 不经过 HTTP 反向代理。

services:
  thirtyfile:
    environment:
      THIRTYFILE_SFTP_ADDR: 0.0.0.0:2022
    ports:
      - "8080:8080"
      - "2022:2022"

将这些项目加入现有 Compose 服务，保留镜像和卷。使用 docker compose up -d 重新启动，仅在必要的网络范围开放所选 TCP 端口。

连接

在客户端选择 SFTP，输入服务器主机名、端口 2022、ThirtyFile 用户名和应用程序密码。此处不接受账号密码。只读应用程序密码无法修改文件，管理员也一样。第一次信任连接前，请核对控制台显示的主机密钥指纹。

sftp -P 2022 amy@files.example.com
# After connecting:
ls
cd "My files"
put report.csv
get report.csv

SSH 公钥

管理员也须开启允许 SSH 密钥。在账号菜单 › SFTP 密钥添加名称和 SSH 公钥，按要求确认当前密码和双因素验证码。私钥请保留在自己的设备。对话框显示指纹和上次使用时间，移除密钥后会停止访问，包括现有连接。

sftp -i ~/.ssh/id_ed25519 -P 2022 amy@files.example.com

SFTP 支持范围

访问权限由 ThirtyFile 角色和共享设置控制。Unix 所有者和权限变更（例如 chmod 600）会被拒绝；创建项目时提供的模式仅供参考。使用 rclone 时请设置 disable_hashcheck = true，因为服务器不提供计算远程校验和的 Shell 命令。若无法访问控制台，请向管理员获取预期的主机密钥指纹。

可列出和下载文件、上传、从指定位置续传、创建文件夹、重命名、移动及移除项目（送到回收站）。写入先暂存，关闭文件时才提交，并应用配额、上传限制、版本及活动记录。断线时丢弃未完成写入。接受客户端时间设置但不保存。不提供 Shell、命令执行、SSH rsync、转发或符号链接。每个账号最多五个连接，每个连接最多 32 个打开项目，闲置五分钟后超时。

首次启动时，服务器在数据目录生成 ed25519 主机密钥，请一起备份。更换密钥会改变指纹，客户端应要求你重新确认。

S3 存储桶

将团队或公司文件夹发布为存储桶。每个 Access Key 只能访问该文件夹，并按创建者当前的权限操作。这与将现有 S3 服务添加为存储位置不同。

端点设置

在控制面板 › 常规 › 应用程序与协议 › S3 启用 S3，输入独立主机名，例如 s3.files.example.com，并选择区域（默认 us-east-1）。S3 默认关闭。代理将此主机名转发至与网站相同的 HTTP 端口，无需新增 Docker 端口。请保留原始 Host 请求头，它是签名的一部分。S3 主机名需要有效的 HTTPS 证书和 DNS 记录。

将以下指令加入 S3 主机名的 HTTPS server 配置块，沿用现有证书设置。请按磁盘容量和空间配额设置适当的上传限制。

location / {
    proxy_pass http://thirtyfile:8080;
    proxy_set_header Host $http_host;
    proxy_request_buffering off;
    proxy_buffering off;
    client_max_body_size 0;
}

发布和密钥

右键点击文件夹并选择发布为 S3 存储桶…，或打开属性 › S3 存储桶。名称必须唯一，由 3–63 个小写字母、数字和连字符组成。重命名或移动文件夹不会改变存储桶名称。

管理员可发布团队或公司文件夹。空间管理者还须有账号的分享权限，并启用允许空间管理者发布存储桶。个人空间及可创建分享链接的人设为无人的空间不能发布。文件夹在回收站内、创建者失去管理权限或空间停用时，存储桶会停止。还原文件夹或访问权限后，已启用的存储桶会恢复工作。

创建一个或多个密钥，填写说明、只读或读写访问权限和可选的到期日。请立即保存 Secret Key，它只显示一次。密钥使用数据目录的 secret.key 加密，请按备份指南保存该文件。已启用密钥到期前三天内，创建者会收到访问权限即将结束的通知。只读空间只能创建只读密钥。

可单独停用或删除密钥，不影响其他密钥。控制面板 › S3 存储桶 列出所有存储桶、创建者、密钥和上次使用时间。停用存储桶会阻止全部密钥；删除存储桶或密钥不会删除文件。Access Keys 不能登录网站、SFTP 或 WebDAV。活动记录会标明存储桶和密钥说明，不会记录凭据。

客户端

在程序中选择 S3 兼容服务：端点 https://s3.files.example.com、区域 us-east-1（或自行设置的区域）、路径样式 URL 和存储桶密钥。不要启用虚拟托管样式 URL、ACL 或服务器端加密设置。

使用 aws cli 时，请交互设置命名配置文件，避免机密出现在命令历史中。将寻址方式设为 path，并在每条命令指定端点。

aws configure --profile thirtyfile
aws configure set s3.addressing_style path --profile thirtyfile
aws --profile thirtyfile --endpoint-url https://s3.files.example.com s3 ls s3://backups/
aws --profile thirtyfile --endpoint-url https://s3.files.example.com s3 cp report.csv s3://backups/report.csv

使用 rclone 时运行 rclone config，选择 S3、提供商 Other，交互输入密钥，设置端点和区域，启用 force_path_style 和 no_system_metadata，将 disable_checksum 设为 true 以停用 rclone 自定义 MD5 元数据（S3 Content-MD5 仍会验证传输），并将 ACL 和服务器端加密留空。rclone copy 可增加文件；rclone sync 可能移除目标文件。

备份和其他用途

使用 restic 时，将备份文件夹发布为 backups，并创建读写密钥。从受保护的凭据存储区加载 AWS_ACCESS_KEY_ID 和 AWS_SECRET_ACCESS_KEY。Repository 密码与 S3 密钥不同，请妥善保管。只在专用的空文件夹中初始化。

restic -r s3:https://s3.files.example.com/backups -o s3.region=us-east-1 -o s3.bucket-lookup=path init
restic -r s3:https://s3.files.example.com/backups -o s3.region=us-east-1 -o s3.bucket-lookup=path backup ./documents

Duplicati 或 Synology Hyper Backup 可使用 S3 兼容目标，设置相同端点、区域和路径样式 URL。请勿在浏览器中编辑备份 repository 文件。此 S3 端点是这些工具的目标，与 ThirtyFile 自身的备份和副本策略不同。

合作伙伴读取价目表时，可将价目表文件夹发布为 price-lists，并创建 90 天后到期的只读密钥。数据团队应为每个 rclone 或 aws cli 任务创建独立密钥，便于分别停用。

文件夹映射和限制

a/b/c.txt 等 key 对应嵌套文件夹和文件；PUT 会创建缺少的父文件夹。以 / 结尾的空对象代表文件夹。列表使用 UTF-8 字节排序、前缀、分隔符和有上限的分页。路径穿越、空路径组件、非法字符或前后空格的名称会被拒绝。不区分大小写的空间会拒绝仅大小写不同的名称冲突。

DELETE 会将文件和文件夹移至回收站。覆盖会按空间策略保留旧版本。空间配额和上传大小限制均适用。MD5 ETag 标识上传内容，服务器会验证 Content-MD5 和支持的 AWS 校验和请求头。分段上传的片段在临时存储区保留最多一天，可中止未完成上传以提前释放。每个密钥最多 32 个、每个存储桶最多 128 个待完成上传（全服务器 512 个），每次最多 10,000 个片段。

支持的操作包括 ListBuckets（仅该密钥的存储桶）、HeadBucket、GetBucketLocation、ListObjects/V2、HEAD、范围和条件式 GET、PUT、同一存储桶内的 COPY、DELETE 和批量删除、分段创建／上传／完成／中止／列出，以及预签名 GET/PUT。预签名 URL 最长有效七天，密钥到期或停用后立即失效。只读密钥即使使用预签名 URL 也不能 PUT。

不提供 ACL、通过 S3 创建存储桶、存储桶策略、生命周期、Object Lock、S3 版本 API、自定义元数据、对象标签、服务器端加密设置或虚拟托管样式 URL。不支持的操作返回 NotImplemented。时钟需与服务器相差 15 分钟以内；错误签名与登录共用失败限制。

FTP 接收文件夹

目前不提供 FTP 接收服务器，仅在无法使用 SFTP 的扫描仪或摄像机有具体需求时规划。将现有 FTP 服务器添加为存储位置是不同功能。

使用案例

服务器可使用 SSH 密钥和 SFTP 脚本上传每晚报表；设计师可使用 Cyberduck 传输大型项目。使用 rclone 时执行 rclone config，选择 SFTP 并设置主机名和端口，核对主机密钥，使用应用程序密码或 SSH 私钥；避免将凭据写入命令历史。
