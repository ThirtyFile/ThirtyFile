密码

修改密码需要输入当前密码和新密码。修改后，其他设备会退出登录。新密码至少需要 6 个字符；如果管理员设置了更高的最低长度，则需满足该要求。

如果密码由管理员设置（新建账号或重置密码），首次登录时需要自行设置密码。忘记密码时，登录页的忘记密码？会向你的邮箱发送链接，前提是管理员已配置邮件服务和网站地址，而且账号已填写邮箱（参阅通知设置）。

两步验证

开启两步验证后，只有密码还不足以登录：输入密码后，还需输入手机身份验证器应用生成的六位验证码，例如 Microsoft Authenticator、Google Authenticator 或 1Password。验证码每 30 秒更换一次，只能使用一次。

  1. 打开两步验证，选择设置，输入密码。
  2. 使用应用扫描二维码。无法扫描时，把二维码下方显示的密钥输入应用。
  3. 输入应用显示的验证码确认，即可开启两步验证。
  4. 保存接下来显示的十个恢复码，例如放在密码管理器中或写在纸上。手机丢失时，每个恢复码可代替验证码登录一次。恢复码只显示这一次。

在同一个对话框中，可以生成新恢复码（旧恢复码随即失效），通过更换应用改用其他手机或应用，或者关闭两步验证。每项操作都需要密码和当前应用的验证码（或恢复码）。

  • 验证码连续错误五次后，必须重新输入密码。一个账号累计十次验证码错误后，系统会拒绝继续验证，最长持续 15 分钟。
  • 单点登录（Microsoft、Google、GitHub 或 OpenID Connect 服务）不要求此验证码：身份提供商有自己的两步验证。应用密码也不要求验证码。
  • 如果管理员要求使用两步验证，下次输入密码登录后会立即要求设置，而且不能关闭。
手机和恢复码都丢失了？请让管理员重置两步验证，然后就可以使用密码登录并重新设置。

已登录设备

设备列出所有已登录你账号的浏览器，包括浏览器和系统、最近使用的地址、登录时间和上次使用时间。当前使用的设备标为此设备。

  • 设备旁的退出登录会立即结束其会话。该设备必须重新登录。
  • 在其他所有设备上退出登录会让当前设备以外的所有设备退出登录。
看到不认识的设备时，请在这里将其退出登录。如果使用密码登录，也请修改密码。如果使用单点登录，这里没有密码：让设备退出登录即可结束其访问权限，也应检查对应外部账号的安全页面。

应用密码

脚本、备份工具和文件客户端无法通过登录页登录。请在应用密码中为每一个工具创建独立应用密码。使用单点登录且没有本地密码的账号也采用这种方式。

  • 为它填写能说明用途的名称，选择只能读取文件还是也能更改文件，并设置到期时间。
  • 输入当前密码；如果开启了两步验证，还需应用验证码。单点登录账号没有本地密码，必须在登录后的 10 分钟内创建应用密码。
  • 每次为账号创建应用密码都会收到通知，帮助你发现非本人创建的密码。
  • 应用密码只在创建后显示一次，请立即复制。系统只保留密码指纹，任何人都无法再次显示原密码。
  • 列表显示每个密码的上次使用时间及来源地址。选择移除后，使用它的工具会立即失效。

通过 Authorization 请求头发送，或者将其作为 HTTP Basic 登录的密码，与用户名一起使用：

curl -H "Authorization: Bearer tfa_…" https://drive.example.com/api/auth/me
curl -u "amy:tfa_…" -o report.pdf "https://drive.example.com/api/files/<file id>/content?download=1"

API 的响应

  • 错误以 JSON 返回：{"error": "…"}，消息为英文，有时另附给程序用的 "code"（例如 upload_discarded）。
  • 状态码：400 无法按要求进行（名称无效，或超过上限，例如 50 个应用密码）；401 未登录，或应用密码无效；403 看得到项目，但不能对它这样做；404 不存在，或不是你看得到的（没有访问权限的项目一律返回“找不到”，不透露它是否存在）；409 冲突（名称已被使用、期间有变动）；413 超过上限或空间大小；429 同时太多，请稍后再试；507 服务器磁盘空间不足。
  • 列表：文件夹的项目以数组返回。加上 ?limit= 时改为分页，返回 {"items": […], "next": "…"}：把 next 作为 ?after= 获取下一页，直到没有 next。

应用密码也能让文件在文件资源管理器、Finder 或兼容的手机文件应用中显示为驱动器：参阅映射为网络驱动器。

应用密码仅用于文件操作：浏览、搜索、下载、上传，以及整理文件与文件夹。不能修改账号密码、创建应用密码、关联登录方式、创建分享链接或使用控制面板，也不会获取 cookie。只读应用密码会被拒绝执行任何更改操作。

修改密码、管理员重置密码或重置两步验证，都会移除所有应用密码；之后需重新创建。让设备退出登录不会影响应用密码，请主动移除不再信任的密码。账号被禁用或删除后，应用密码随即失效。错误的应用密码与错误的登录密码共用同一限制：同一地址失败 30 次后，必须等待 15 分钟。

语言

账号菜单中的语言决定 ThirtyFile 的显示语言。选择会随账号保存，因此在其他电脑和手机登录后也会使用同一语言。尚未选择时，使用管理员设置的默认语言或浏览器语言。登录页和分享链接使用浏览器语言，或页面底部列表中选择的语言。

界面风格

账号菜单中的界面风格决定文件浏览器的布局和按键行为。默认的自动按照当前电脑选择：Mac 使用 Mac 风格，Windows、Linux 和 ChromeOS 使用 Windows 风格。手机和平板在两种风格下使用相同布局。选择随账号保存。无论选择哪种风格，修饰键始终跟随电脑：Mac 使用 ⌘，其他系统使用 Ctrl。

  • Windows 风格：类似文件资源管理器，包含地址栏、文件夹树和命令栏。参阅文件操作。
  • Mac 风格：类似 Mac 的 Finder，包含分组侧边栏、路径栏、可在列表视图原地展开的文件夹、快速查看和 Finder 快捷键（Enter 重命名，⌘ + ↓ 打开）。参阅Mac 风格。

两种风格具备相同的文件功能，替换或删除项目前也会询问同样的确认问题。

登录历史

我的登录历史显示成功登录、失败尝试、退出登录、修改密码，以及应用密码的创建、移除或使用错误密码的记录，并列出对应地址和浏览器。

通知

右上角标签页旁的铃铛会通知以下情况：

  • 与你共享：有人向你共享文件夹或文件，或者将你加入空间（直接加入，或通过你所属的用户组）。给所有人的访问权限不会通知；已有权限的变动也不会通知。
  • 空间即将用满：你拥有或管理的空间已用满 90%。包含个人空间，以及你是所有者或管理者的团队空间。只通知一次，直到空间恢复可用容量后再次接近用满才重新通知。
  • 访问权限即将结束：别人给你的访问权限将在 3 天内到期。如果最初设置的期限不足 3 天，共享通知本身已说明期限。
  • 通过链接收到文件：有人通过你创建的收件链接上传文件。同一链接在一小时内持续收到的文件合并为同一通知，只发送一封邮件（即使只选择邮件通知也一样）。
  • 新应用密码：账号创建了应用密码，同时显示创建时使用的地址。
  • 新登录方式：Microsoft、Google、GitHub 或 OpenID Connect 单点登录账号已关联到你的账号（参阅自行关联账号）。

铃铛上的数字表示未读通知数。点击通知可打开对应项目。列表底部提供全部标为已读和清除全部。通知保留 90 天。

铃铛列表底部或账号菜单中的通知设置可以分别开启或关闭每类应用内通知和邮件通知。邮件发送到这里填写的邮箱地址。使用单点登录时，首次会填入外部账号提供的地址，之后可以修改。留空则不收邮件。密码重置链接也发到这个地址，因此修改地址需要当前密码（两步验证账号还需验证码；无密码账号需在登录后 10 分钟内修改），原邮箱也会收到变更通知。同一地址每 15 分钟最多收到五封同类邮件；应用内通知全部保留。

只有管理员配置邮件服务器后才会发送邮件（参阅通知邮件）。邮件采用你选择的语言；没有选择时使用管理员设置的默认语言，否则使用你最后使用 ThirtyFile 时的语言。时间按你的时区显示。
