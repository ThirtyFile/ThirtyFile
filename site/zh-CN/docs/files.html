文件操作

ThirtyFile 的操作方式类似文件资源管理器；使用Mac 风格时则类似 Mac 的 Finder。本页介绍可用操作与加快操作的快捷键。

导航界面

  • 左侧菜单：最近使用的文件、收藏、空间、与你共享的项目、分享链接、回收站、你的智能文件夹与标签。
  • 标签页：同时打开多个文件夹或文件。按 + 添加标签页，或以鼠标中键按文件夹，在新标签页打开。
  • 地址栏：显示所在位置。按路径任一部分即可前往；按路径旁空处（或 Ctrl + L）可查看完整路径、复制路径，或输入／粘贴另一个路径后按 Enter 前往（参阅路径）。
  • 搜索：在当前文件夹与子文件夹中寻找名称包含输入文本的项目（从最近使用、收藏等列表搜索时，范围是所有可访问位置）。所有语言都不区分大小写；输入三个以上字符时也不区分重音符号。结果页可扩大范围到所有位置，并依类型、修改日期、大小与标签筛选。最多显示 300 笔，超过时会提示。保存为智能文件夹可保留搜索条件（参阅智能文件夹）。
  • 查看：选择列表呈现方式（参阅视图、列与分组）。右下角两个按钮可切换详细信息与大图标。

最近使用依新到旧列出你上传、编辑或打开的文件，不论位于自己的空间或共享空间／文件夹。打开是指在浏览器查看（查看器、编辑器或预览窗格）；下载与使用应用密码的文件客户端不计入。无法再打开或已在回收站的文件会略过。

大型文件夹

数千个项目的文件夹会立即显示第一批项目，之后按需加载你滚动到、以 End／Page Down 前往，或拖动滚动条到的部分。尚未加载的列短暂显示灰线，状态栏显示正在加载更多项目…。状态栏计算文件夹全部项目，包括尚未加载的。只有附近部分保留在内存，因此十万个项目也不会拖慢浏览器。

选择可涵盖整个文件夹，包括尚未加载的项目：

  • Ctrl + A（或全选）选择文件夹全部项目。Ctrl + 点击可取消个别项目；状态栏显示选择数量。
  • Shift + 点击，或 Shift + End，会选择两个项目之间的全部内容，不论距离多远。
  • 移动、复制、剪切粘贴、拖动、加入收藏、标签、移到回收站与永久删除，都会处理全部选择项目。ThirtyFile 每次处理一千个，底部消息显示进度；这类大型变更无法从消息撤销。
  • 一次下载或创建 ZIP 最多处理 10,000 个项目；更多时请下载文件夹本身。
  • 详细信息窗格显示选择数量；选择整个文件夹时会显示总大小。

输入名称开头会跳到已加载项目中下一个符合的项目。向上（或返回）回到大型文件夹时，无论原文件夹在列表何处，都会显示并选择它。依日期或类型分组（见下方）会加载整个文件夹，确保每个分组完整。

视图、列与分组

查看菜单包含文件资源管理器的各种视图，以及分栏：

  • 大图标与中图标：图片、PDF 与视频缩略图（参阅缩略图），名称显示在下方。
  • 列表：小图标与名称并排分栏，便于一次查看许多项目。
  • 详细信息：每行一个项目，附各列。
  • 平铺：缩略图旁显示名称、类型与大小。
  • 分栏：从空间顶层到当前文件夹，每层各有一栏。选择文件夹会在右侧下一栏显示内容；选择文件会显示预览栏，包含图片、类型、大小、日期及打开、下载、分享按钮。手机本来就一次显示一个文件夹，因此不提供此视图。

在分栏中，↑／↓在栏内移动，→进入所选文件夹的栏，←返回前一栏；输入名称开头可跳到项目。按其他栏的项目会前往该栏。返回时会保留右侧已打开的栏，直到另选项目。选择、打开、重命名与删除和其他视图相同，大型文件夹也会分批加载；可将项目拖到任何栏的文件夹，或另一栏的空处以移动。拖动栏右边缘可调整宽度（双击恢复默认）；宽度会在此浏览器保留到退出登录。分组依据不适用此视图。

没有缩略图的文件显示类型图标。程序语言与数据格式各有专属图标（JSON、Rust 与 Go 不同）；常见工具文件即使没有扩展名，也可依名称辨识：Dockerfile、Makefile、.env、.gitignore、package.json、锁文件、LICENSE 与 README。字体、磁盘镜像、安装程序、数据库、电子书、设计文件、3D 模型与证书也有图标。在详细信息将光标移到类型栏可查看文件种类。无法辨识的文件维持普通文件图标。

在详细信息中，拖动列标题边缘可调宽度（或用 Tab 选择边缘后以方向键调整）；双击边缘恢复默认。右键按列标题，或选择查看 › 列，可选择修改日期、创建日期（默认隐藏）、类型、大小、标签（默认隐藏），以及列表适用时的位置与上传者。恢复默认列可撤销调整。列表太窄而容不下全部列时（例如打开详细信息窗格），会先隐藏类型再隐藏大小，之后才横向滚动。手机只显示名称与大小。

排序可依名称、修改日期、创建日期、类型或大小，由 A 到 Z 或反向排列；按列标题也相同。文件夹永远在前。名称排序类似文件资源管理器：不区分大小写，数字依数值排序（File 2 在 File 10 前）。其他字符依 Unicode 码位排序，因此中文与日文依 Unicode 顺序（平假名、片假名、汉字），不是读音或笔画。所有语言与用户的顺序一致，让大型文件夹分页加载不会遗漏或重复。

查看 › 分组依据会将项目分组，各组标题附项目数：

  • 类型：文件夹在前，其余每种文件类型各一组。
  • 修改日期：今天、昨天、本周早些时候、上周、本月早些时候、上个月、今年早些时候与很久以前（每周从星期一开始）。

组内仍依列表排序。若按相同依据反向排序（旧到新，或类型 Z 到 A），分组顺序也会反向。视图、列与分组设置会在浏览器中对每个文件夹保留。

路径

路径在地址栏与 WebDAV 中都用相同方式表示文件夹或文件，从包含所有空间的顶层开始，例如 /My files/Reports/2026.xlsx：

  • / 是所有空间。
  • 我的文件是个人空间（管理员可能未提供）。公司空间（全部文件，除非管理员改名）与团队空间使用各自名称。同名时后创建者加上编号，例如专案 (2)，WebDAV 使用相同编号。
  • 与我共享包含其他人从你不是成员的空间分享的文件夹与文件：/Shared with me/Plans/Q1。同名分享项目也会编号。

ThirtyFile 提供的名称（我的文件、全部文件、与我共享）依所选语言显示，输入路径时可使用该语言或英文。不区分大小写，\ 等同 /，也可粘贴 WebDAV 地址或 ThirtyFile 页面链接。路径不存在或无权访问时，地址栏会提示并保留输入供修正。最近使用、收藏、回收站等列表不在空间中，因此不能输入其路径。

管理员也可输入控制面板路径：/Control panel/Storage locations，或所选语言中显示的名称。从控制面板地址栏复制的路径也可使用。若需要不受语言影响的路径，可用 /admin、/admin/storage、/admin/usage 或其他控制面板页面地址。Windows 地址栏与 Mac 风格的前往文件夹都支持。所需管理员权限和从菜单打开相同。辨识到的控制面板路径优先于同名空间；请从侧栏打开该空间，或粘贴其完整页面 URL。

上传

  • 把电脑上的文件或整个文件夹拖入列表。放到列表、文件夹树、地址栏或标签页中的文件夹，可上传到该文件夹；也可以
  • 按新建，选择上传文件或上传文件夹。

右下角显示进度，每个文件会立即开始传送。超过 100 个文件时，只列出传送中、暂停与失败的，其余在下方显示数量。右键按列表可一次重试所有失败文件。上传未完成时，浏览器会在关闭或重新加载页面前询问。无法读取的拖入项目（没有权限或已移除）会略过，消息显示数量。

传输开始前显示正在准备上传…。所有字节传完后，正在完成上传…会一直显示到服务器确认保存完成。这两个阶段使用等待指示器，没有完成百分比；仍可暂停与取消。

两分钟未收到上传数据时，服务器停止等待，上传可从已收到的字节继续。持续传送数据的长时间上传没有总时限。WebDAV 使用相同闲置限制，但失败的 WebDAV 请求必须完整重送。

中断的上传

上传期间重新加载页面或关闭标签页／浏览器，下次在同一浏览器打开 ThirtyFile 时，右下角中断的上传会依原加入方式显示：文件夹以名称显示，一起选择的文件为同一笔。浏览器无法自行重开你的文件，因此请再次选择：

  • 继续会要求相同文件（文件夹则选相同文件夹）。各文件依服务器已保存进度继续，使用同一目标文件夹与同名冲突处理选项。继续前会检查整份文件，包括大小与日期未变的内容变更；大文件读取可能需要时间。此检查会在原上传传送时读取文件，因此尚未读完整就中断的文件，以及旧版本保存的上传，都会重新开始。可以继续表示服务器仍保有已传送内容，否则从头开始。
  • 文件先依文件夹路径与名称配对，再要求大小、日期与内容和原先一致。期间修改或被同名文件替换的会重新开始，不会接到旧片段。选到不属于原上传的文件会略过，未选到的中断文件继续等待。
  • 服务器在中断前刚完成的文件不会上传两次。若服务器已无法辨识先前完整传送的文件，列表会提示可能已上传；重试前请检查文件夹。
  • 重新开始会从头上传所选文件，放弃会移除任务及服务器已收到的部分。

其他标签页仍在执行的上传不会提供恢复，只有该标签页关闭后才会出现。中断上传在此浏览器保留七天，只属于你的账号（访客则属于其上传使用的分享链接）。只保存文件名称、文件夹、大小、日期与服务器上传地址（访客也包含分享链接），不保存文件内容。退出登录会移除这些记录。

下载

选择一个或多个项目，按下载。多个项目或文件夹会合成一个 ZIP，内容反映下载开始时的状态，期间添加到文件夹的项目不会包含。若服务器文件夹内的文件在传送 ZIP 时大小改变，下载会失败，而不是传回不完整内容；请重新开始。

右下角显示进度。超过 256 MB（手机与平板为 64 MB）的下载会直接进入浏览器自己的下载列表，避免页面把内容放在内存。

准备下载链接或等待服务器响应时，显示正在准备下载…，等待期间可取消。大小未知时，以等待指示器替换百分比，但仍显示已收到的字节数。准备失败可重试。直接交给浏览器的下载（包含公开分享下载）会提示到浏览器下载列表追踪进度。

一次最多下载 10,000 个所选项目。更多时请下载所在文件夹；无论内容多少，一个文件夹只算一个项目。

压缩与解压缩 ZIP

  • 压缩：选择项目，右键选压缩为 ZIP 文件，旁边会出现以项目命名的 ZIP（多个项目则以所在文件夹命名），像普通文件计入空间用量。压缩前，ThirtyFile 会确认所选项目的完整大小能容纳于空间配额与数据目录的可用容量，因为 ZIP 在数据目录组合。
  • 解压缩：右键按 ZIP，选全部解压缩。内容放到旁边以 ZIP 名称命名的新文件夹，名称已占用时加编号。

两者都在服务器执行，底部消息显示进度，期间可继续工作，活动日志也会记录。

为避免单一文件耗尽服务器，符合以下条件的 ZIP 不会解压缩：

  • 内容超过空间可用容量，或大于 16 GB；
  • 文件与文件夹超过 20,000 个，包含路径经过的中间文件夹；
  • 内部路径超过 64 层文件夹；
  • 内容膨胀远高于普通文件（超过压缩大小 250 倍），例如“ZIP 炸弹”；
  • 内部名称导向新文件夹之外（../ 或完整路径），或名称不允许（例如含 : 或 ?）；
  • 有密码保护，或使用普通 deflate 以外的压缩方法。

整理

  • 添加文件夹或文本文件：按新建、用 Ctrl + Shift + N 建文件夹，或右键按空处选新建。和文件资源管理器相同，项目立即出现在列表末尾，名称可直接输入；命名后仍留在末尾，直到刷新（F5）、变更排序或离开文件夹。创建失败时会移除并提示原因。
  • 选择：按项目。按住 Ctrl 加选，Shift 选范围，或拖动框选。
  • 移动：拖到文件夹、剪切粘贴，或右键选移动到…。可放到列表或文件夹树的文件夹（停在未展开文件夹上片刻可展开）、地址栏路径片段或文件夹标签页。移动到…窗口中的新建文件夹会在当前查看的文件夹内创建并打开新文件夹。
  • 复制：拖放时按住 Ctrl（Mac 为 Option）、复制粘贴，或右键选复制到…。
  • 重命名：按 F2，或和文件资源管理器一样按已选项目的名称，稍候即可编辑（双击则打开）。文件夹树可按当前打开文件夹的名称。Enter 保留新名称，Esc 保留旧名称。
  • 右键按项目可使用其他功能。和 Windows 11 类似，菜单顶部是一排剪切、复制、重命名、分享与删除按钮（光标停留可查看名称），下方依序有打开、下载、压缩、收藏、标签、分享链接、移动到、复制到与内容。
  • 右键按列表空处可使用查看、排序方式、分组依据（与工具栏相同）、撤销（名称反映操作，例如撤销删除）、刷新、粘贴、新建 › 文件夹或文档、上传 › 文件或文件夹，以及内容。

移入或移出服务器上的文件夹会复制文件，大型文件夹可能需要时间。底部消息显示进度，期间可继续工作；关闭页面后服务器仍会接续移动或复制。

移动、重命名或删除后，底部消息会短暂提供撤销按钮，将项目移回、恢复旧名或从回收站还原。在列表按 Ctrl + Z 也会撤销最近一次这类操作。

标签

标签是加在文件与文件夹上的彩色标记，例如紧急或发票，方便之后寻找。一个项目可以有多个标签。

  • 为项目加标签：右键选标签，再选标签。勾号表示所有选择项目都有，横线表示只有部分有；选横线会加到全部项目，选已勾选者会移除。新建标签…会创建并加到项目。详细信息窗格的编辑标签可对单一项目做相同操作。
  • 查看标签：名称后以彩色圆点显示，光标停留可读取名称。详细信息窗格依名称列出，详细信息视图的标签栏也一样。
  • 寻找标记项目：按左侧标签下的标签，列出所有位置含该标签的项目。搜索结果也可依标签筛选。
  • 修改标签：右键按左侧标签（或用列表上方工具栏）可改名、换色或删除。删除会从所有项目移除标签，项目本身不受影响。标签旁的 + 可添加。

标签只属于你。其他人看不到标签、名称与应用项目，共享空间内也一样；管理员与分享链接访客也看不到。每个人都可为有权打开的项目加上自己的标签。项目重命名、移动（包含跨空间）、移入回收站及还原，或被其他程序在服务器文件夹修改时，标签仍保留；你创建的副本也继承原标签。无权再打开项目后不再显示其标签；永久删除项目会移除标签。与分享链接相同，标签保存在数据库：备份 data 文件夹会保留，文件备份不会。

智能文件夹

智能文件夹是保留的搜索条件，像文件夹显示在左侧菜单，每次打开都列出当时符合条件的项目，例如最近 30 天修改的 PDF或所有标为紧急的项目。

  • 创建：搜索并使用筛选条件，按保存为智能文件夹。命名并确认条件后按创建。左侧智能文件夹旁的 + 可从空条件创建。
  • 搜索条件：名称片段；文件、文件夹或类型（文件、图片或自行输入扩展名）；修改日期（今天、最近 7／30 天或一年，每次打开重新计算，或两个日期之间）；大小（默认范围或两个大小之间）；你的标签（同时含所有勾选标签）。范围可为文件夹及子文件夹、一个空间，或所有有权访问的位置。
  • 打开：按智能文件夹下的项目。列表附各项目位置，可像普通文件夹排序、分组、选择、打开、改名、移动、分享、加标签与删除。大量结果和大型文件夹一样分批加载。
  • 修改或删除：右键按左侧项目，或使用列表上方的编辑…与删除智能文件夹；工具栏也会说明搜索条件。

智能文件夹本身不存项目。删除只移除保存的搜索条件，也不能把项目搬进去；项目符合条件时才显示，重命名、移动或修改后不符就离开。和标签相同，智能文件夹只属于你，其他人看不到。它永远只列出你当下可打开的项目；失去文件夹或空间权限后，相关项目会消失，以无权打开文件夹为范围的智能文件夹会列出空。数据保存在数据库：备份 data 文件夹会保留，文件备份不会。

详细信息

按工具栏详细信息窗格或 Alt + Enter，打开右侧窗格，显示所选项目；未选择时显示当前文件夹。

  • 大小与包含：文件夹计算所有层级内容的大小与文件／文件夹数，不含回收站。大型文件夹可能需要一些时间。
  • 选择多个项目时，显示合计文件与文件夹数（含所选文件夹内的项目）与总大小。
  • 标签：依名称列出你的标签，可用编辑标签修改（参阅标签）。
  • 活动：谁在何时上传、编辑、重命名、移动、复制、删除或还原。文件夹包含当前里面所有项目的活动（含回收站项目）；空间根目录则涵盖整个空间。只显示最近 50 笔。

有权打开项目的人都能查看活动。分享与权限变更（谁取得权限、分享链接）只有空间管理者与所有者可见。完整记录、筛选与导出仍在活动日志。

名称已被使用时

上传、移动、复制、粘贴或从回收站还原前，ThirtyFile 会检查目标是否有同名项目（不区分大小写，服务器上的文件夹除外）。每个冲突都显示双方大小与日期，并询问：

  • 替换：上传文件会将内容写入既有文件，保留其分享、权限与收藏，原内容保存为先前版本。移动、复制或还原时，原项目会移到回收站，仍可救回。之后若移动或复制到服务器上的文件夹（或从中移出）失败，原项目会从回收站回到原处。
  • 略过：不处理此项目。
  • 保留两者：新项目加上编号，例如 Report (1).docx。上传列表会显示保存名称。

勾选将此选择应用到接下来的冲突，可对剩余冲突使用相同答案；或选取消停止，不变更任何内容。同名的上传文件夹会合并到既有文件夹：替换会替换内部同名文件，保留两者保留两份。把副本贴回自己的文件夹时，和 Windows 一样总会加上编号。

上传完成前，若目标文件夹删除或你失去添加文件权限，上传会失败并在列表提示原因，不会把文件存到其他地方。

先前版本

在在线编辑器保存、以上传替换或还原先前版本时，原本内容会保存为先前版本。选择文件并打开详细信息窗格（Alt + Enter），版本会由新到旧列出作者与时间。打开在新浏览器标签页查看，下载保存该版本，还原将其作为当前内容；还原前内容也会成为版本，因此可用相同方式撤销还原。

  • 默认每个文件保留最新 20 个版本，每个保留 90 天。管理员可在控制面板 › 常规修改两项限制或关闭版本功能。
  • 先前版本不计入空间配额；管理员可在控制面板 › 存储用量查看占用量。
  • 重命名或移动（含跨空间）会保留版本；副本从没有版本开始。永久删除文件也会删除版本。
  • 有权打开文件的人都能查看与下载版本，还原需有编辑权限。

Mac 风格

Mac 风格（参阅界面风格）让文件浏览器采用 Finder 版面与按键。文件、可用操作与确认问题和 Windows 风格相同：同名冲突仍会出现名称已被使用时的对话框，永久删除总会先确认。

  • 侧栏：与 Windows 风格左侧菜单相同位置，以分组放在内缩、半透明圆角面板。收藏包含所有收藏、收藏的文件夹与智能文件夹（标题旁 + 可新建）。接着是空间、分享（与我共享、我的分享链接）、最近使用、回收站与标签。按标题可隐藏／显示分组，项目与文件可拖放到里面的文件夹或空间。
  • 工具栏：返回／前进、当前文件夹名称、视图（图标、列表、分栏、画廊）、排序方式、分组依据、分享、标签，以及提供其余功能的操作（⋯）：添加文件夹、上传、快速查看、显示简介、重命名、复制、粘贴、移动到这里、移到回收站、收藏、标签、前往文件夹…与快捷键。搜索框在右侧，导航与命令使用圆角胶囊。窄窗口的视图按钮改为菜单，排序、分组、分享与标签保留在操作中，工具栏维持单行。分栏与画廊不提供分组。
  • 路径栏与状态栏：默认隐藏。打开视图选项（视图按钮旁箭头，窄窗口则为查看），打开显示路径栏或显示状态栏。选项依账号在此浏览器保存，不会跟随到其他浏览器。状态栏保留项目数与存储用量，路径栏位于窗口底部，显示当前文件夹路径。按其中文件夹可前往，拖放项目可移动到该处。没有直接输入路径的方框；前往文件夹（⌘ + Shift + G）会要求输入，详见路径。
  • 标签页：打开两个以上标签页才显示标签页列。即使隐藏，仍可在新标签页打开文件夹与使用标签页快捷键。
  • 列表：紧凑交替底色行，有缩略图时显示小缩略图。默认列为名称、修改日期、大小与种类，日期使用界面语言的完整格式。上传者等列可从视图选项 → 列打开；列选择与宽度和另一风格分开保存。文件夹名称旁有三角形，按它或 → 可直接在下方缩进展开；← 或再次点击折叠。这种大型文件夹会和普通大型文件夹一样，随滚动分批加载。
  • 画廊：上方大型预览与打开文件相同（图片、视频、PDF、Office 与文本，其他类型显示图标），下方缩略图列。打开文件夹时先选第一项。→／←前往下一／上一项，Home／End到第一／最后一项，Space打开快速查看；缩略图列跟随滚动，大型文件夹分批加载。停留在项目后才加载预览，视频不会自动播放。右侧面板显示类型、大小、日期与标签，并提供打开、下载、分享、重命名、移到回收站；缩略图列末端按钮可显示／隐藏面板（此浏览器会记住）。选择、复制、移动、拖到文件夹与右键菜单和其他视图相同；Enter可在预览上方名称处重命名。此视图不支持分组依据，手机也不提供。
  • 快速查看：按 Space在列表上方窗口预览所选项目，内容和打开文件相同。方向键切换上一／下一项，列表选择也跟著变更；选择多项时只依序预览它们。Space 或 Esc关闭，打开则正式打开项目。
  • 移动：没有剪切。先复制（⌘ + C），到目标文件夹后选移动到这里（⌘ + Option + V）移动，或用粘贴（⌘ + V）创建副本。拖动与 Windows 风格相同。
  • 添加项目立即进入排序后的正确位置；按已选名称不会重命名，请按 Enter。
  • 外观：文件夹与文件使用专属图标（文件页面显示格式名称或符号）、强调色圆角选择、半透明侧栏与低调工具栏按钮，明暗模式都适用。
  • 手机上的 Mac 风格和 Windows 风格的版面、菜单和按键相同，但保留自己的外观和图标。

按键和 Finder 相同，但浏览器保留的按键除外（如 ⌘ + N、⌘ + W）。非 Mac 电脑使用 Ctrl 代替 ⌘，Alt 代替 Option。其他按键与上方 Windows 风格相同：列表移动、⌘ + A、⌘ + Z、Shift + F10、F5、输入名称开头、Esc、?。

回收站

删除项目会进入回收站，可从中还原。30 天后永久移除（管理员可用THIRTYFILE_TRASH_DAYS修改，或保留到清空），手动清空也会永久移除。页面显示实际保留天数。

回收站列出所有你可打开空间的删除项目。清空回收站只删除你管理的空间（自己的文件、你为管理者的团队空间），会先列出各空间与删除数量供确认。只有查看权限的空间项目会留下。

永久删除大型文件夹或清空大量回收站可能需要时间。项目立即从回收站消失，底部消息显示删除进度，关闭页面仍继续。将数千项文件夹移到回收站、还原，或在服务器文件夹重命名，也需要片刻。完成前该文件夹无法还原、移动或复制，会提示稍后再试。

较宽屏幕的删除者栏显示移到回收站的人。早于记录功能删除或账号已移除的显示横线。列表上方由我删除只看自己的操作，所有人删除恢复完整列表。

手机操作

同一网站也可用于手机。点项目打开，其余使用列表上方按钮。

  • 选择：长按项目片刻以选择，之后点按可加入／移出选择。平板也会打开所选项目菜单。
  • 操作所选项目：选择时，底部工具栏提供下载、分享、移动、删除与更多（剪切、复制、重命名等）。×清除选择。列表上方保留导航窗格（空间与文件夹树）、新建、排序、查看、···与详细信息窗格，有内容可粘贴时也有粘贴。
  • 复选框：打开查看 › 项目复选框，每种视图的项目都会显示复选框。
  • 上传：选新建 › 上传文件或上传文件夹。
  • 地址栏：长路径显示末端，也就是当前文件夹；滑动可查看上层路径。
  • 主屏幕：把网站添加到主屏幕（Safari：分享 › 添加到主屏幕；Chrome：添加到主屏幕或安装应用），之后会像应用打开，不显示浏览器工具栏，使用网站名称与标志。
