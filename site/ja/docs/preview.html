ブラウザーで開けるもの

種類表示編集
画像（.jpg、.png、.gif、.webp、.avif、.svg、.bmp、.ico）可能
動画（.mp4、.webm、.mov）可能
音声（.mp3、.wav、.ogg、.flac、.aac、.m4a）可能
PDF可能
Word（.docx）可能可能
PowerPoint（.pptx）可能
Excel（.xlsx）可能可能
Markdown（.md）書式付きのページとして表示可能
テキストとコード。HTML と XML も含む（ページとして実行せずテキストで表示）可能可能

ファイルをダブルクリックするとタブで開きます。同じフォルダーの前後のファイルへは ←、→、またはツールバー右側の矢印で移動します。フォルダーの並べ替え順に移動し、全件を読み込むとステータスバーに位置（たとえば 12 件中 3 件目）を表示します。ファイルに入力中、または動画の操作部分にカーソルがあるときは、矢印キーはその場所の通常の操作になります。先に外側をクリックしてください。

5 MB を超えるテキストやコード、50 MB を超える Word、PowerPoint、Excel はブラウザーで開くには大きすぎるため、ダウンロードしてください。

ほとんどのブラウザーは HEIC、TIFF、Photoshop の画像、AVI、MKV、WMV、FLV の動画、WMA、AIFF の音声を表示できず、ダウンロードボタンを表示します。対応形式でも、その動画や音声をブラウザーが再生できない場合は同様です。

Excel ブックを編集する

ブックを開いて ブックの編集 をクリックします。

  • セルまたは数式バーに入力します。数式は = で始めます。
  • シートの大部分への COUNTIF など、数百万のセルを 1 つずつ調べる数式は、ページの動作を遅くする代わりに #CALC! を表示します。保存時は Excel が保存していた結果を保持し、Excel で開くと再計算します。
  • ツールバーで太字、色、罫線、配置、数値書式、セルの結合を操作します。日付の月名、曜日名、AM/PM は、セルの書式が独自の言語を指定しない限り、ThirtyFile の表示言語を使います。関数名はファイルに保存されるとおり英語のままです。
  • セル間と、コンピューターの Excel との間でコピー、貼り付けができます。
  • 切り取りは同じブック内でセルを移動します。別のブックへ貼り付けると、値、数式、書式をコピーし、元のセルは保持します。同じブック内の移動は元に戻せます。
  • コピー、貼り付け、連続データの入力は、一度に最大 100,000 セルと約 800 万文字のクリップボードテキストを受け付けます。シート外にはみ出す貼り付けは、セルを変更する前に拒否します。空白の多い大きな選択範囲の消去は、内容のあるセルだけを対象にし、最大 100,000 件まで変更できます。それ以上は範囲を分けてください。
  • 数式バーと名前ボックスでは、入力メソッドの候補決定や取り消しに使う Enter、Escape はそのまま入力メソッドに渡します。変換後にもう一度 Enter を押すと、値の確定や移動ができます。
  • 挿入 と 削除 メニューから行、列を挿入、削除できます。数式も自動で調整します。
  • Ctrl + Z で元に戻し、Ctrl + S で保存します。最大 200 操作を元に戻せ、そのうち行、列の挿入、削除は最大 20 操作です。
  • スクリーンリーダーでは矢印キーで移動すると、移動先のセルのアドレスと値（または選択範囲）を読み上げます。

閲覧のみのブックでは、シートの後にある表から画面内のセルをスクリーンリーダーで参照できます。矢印キーでシートをスクロールすると、その表も追従します。

保存は編集したセルだけを変更し、グラフ、画像、ほかの要素はそのまま保持します。

20 MB を超えるブックは閲覧できますがオンライン編集はできません。ダウンロードして Excel を使ってください。

Word 文書を編集する

文書を開いて 文書を編集 をクリックします。文書は 1 枚の長いページとして、フォント、サイズ、間隔、リストの番号を保ったまま表示されます。編集中は改ページ、ヘッダー、フッターは表示されません。

  • 一般的なエディターと同じように文字を入力、削除、選択できます。Enter で同じ設定の新しい段落を始め、Shift + Enter で改行し、Tab でタブを入力します。
  • 新しく入力した文字は、入力した位置の書式になります。太字の中で入力した文字は太字になります。
  • 貼り付けはプレーンテキストだけです。各行が 1 つの段落になります。
  • リンクをクリックするとカーソルがリンク内に置かれます。Ctrl + クリック（Mac では ⌘ + クリック）でリンクを開きます。
  • 表、画像、ページ番号などのフィールド、変更履歴、コメント、脚注、数式はそのまま表示され、ここでは変更できません。それらを含む段落も変更できません。ポインターを合わせると枠が表示されます。表が隣の段落と結合されることはありませんが、表をまたいで選択して削除すると表も削除されます。
  • 太字やスタイルなどの書式は、ここではまだ変更できません。
  • Ctrl + Z で元に戻し、Ctrl + S で保存します。保存していない変更は、別のファイルやタブに移って戻ってきても残ります。

保存すると、編集した段落だけが変更されます。文書のほかの部分はそのまま残り、以前の内容は以前のバージョンとして保存されます。

20 MB を超える文書は表示できますが、オンラインでは編集できません。ダウンロードして Word で編集してください。

テキストファイルを編集する

テキストとコードは、多くのプログラミング言語を色分けするエディターで開きます。Ctrl + S で保存します。

保存中にタブを切り替えても、各ファイルの編集内容は別々に保持します。保存開始後の入力は、保存が完了しても未保存のままなので、もう一度保存してください。下書きを破棄してから以前の保存が完了しても、下書きが戻ることはありません。

Dockerfile、README、珍しい拡張子など、認識できないファイルには このファイル形式はプレビューできません と表示します。テキストなら テキストエディターで開く で読み、編集できます。名前や形式は変わらず、保存操作をするまではファイルを保存しません。既定の表示 で戻れます。未保存の変更は保持し、エディターを開き直すと戻ります。

  • 変更権限がある場合のみ保存できます。共有リンクではダウンロードが許可されている場合のみボタンを表示し、テキストは読み取り専用です。
  • テキストに見えないファイル（プログラム、変わった拡張子の画像）は読み取り専用にし、保存で壊さないようにします。書き戻せない文字コードも同様です。UTF-8、UTF-16、Windows の改行は保持します。Big5 は読めますが、警告のとおり保存時に UTF-8 に変換します。開くだけなら保存されたファイルは変わりません。
  • 5 MB を超えるファイルはエディターで開けません。ダウンロードしてください。

Markdown

Markdown は、見出し、一覧、表、タスクリスト、コードを書式付きのページで表示します。ページ上の 編集（閲覧権限のみなら ソース）でテキストを変更し、プレビュー に戻ると未保存の変更も含めて結果を表示します。

安全に表示するため、ファイルの HTML は実行せず、ThirtyFile の外観を装うこともできません。リンクは新しいタブで開き、画像はファイル自体に埋め込まれたものだけ表示します。他サイトの画像は表示しないため、ファイルを開いたことをそのサイトに伝えません。

サムネイル

アイコン表示（大アイコン、中アイコン、タイル）では画像、PDF、動画にサムネイルを表示します。画像はサーバーで作成します。PDF の最初のページと動画の冒頭付近のフレームは、変更権限のある人の最初のブラウザーが作成してサーバーに保存し、その後は同じスペースでファイルを開ける全員に表示します。それまでは閲覧のみの人は自分のブラウザーで作ったものを見ます。再生できない動画と 200 MB を超える PDF はアイコンのままです。保存先は data/thumbs です。コンテンツストアのファイルの内容が完全に削除されるとそのサムネイルも削除し、30 日間誰にも表示していないものも削除します（次に見ると再作成します）。

2 人が同じファイルを編集する場合

編集中にほかの人が保存した場合、知らせずに上書きしないよう、保存を停止して通知します。自分の変更をコピーし、ファイルを読み直して変更を加え直してください。
