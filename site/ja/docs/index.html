インストール

ThirtyFile は Docker で動きます。次の 2 つの方法のどちらかを選んでください。どちらも 1 分ほどで終わります。

日本語で読めるのは、インストールと初期設定の 2 つのガイドです。その他のガイドは、現在英語のみです。

始める前に

ファイルを保存するパソコンかサーバーに Docker をインストールしてください。ほかには何も要りません。

方法 1：docker run

docker run -d --name thirtyfile --restart unless-stopped \
  -p 8080:8080 \
  -v /srv/thirtyfile/data:/data \
  -v /srv/thirtyfile/storage:/storage \
  -e THIRTYFILE_ADMIN_PASSWORD='choose-a-password' \
  ghcr.io/thirtyfile/thirtyfile:latest

Docker Hub でも同じリリースのイメージを提供しています。上のコマンドで thirtyfile/thirtyfile:latest を指定すると、そこからインストールできます。Compose の場合は image: 行の ghcr.io/thirtyfile/thirtyfile を thirtyfile/thirtyfile に置き換え、バージョンタグと既存のボリューム設定はそのままにしてください。

部分役割
-p 8080:8080サイトにアクセスするポートです。ポート 80 にするには -p 80:8080 と書きます
-v /srv/thirtyfile/data:/dataアカウントと設定の保存先です。更新しても残ります
-v /srv/thirtyfile/storage:/storageファイルの保存先です。別のディスクや、マウントした NAS も使えます
THIRTYFILE_ADMIN_PASSWORD最初のアカウントのパスワードです。choose-a-password は自分のパスワードに置き換えてください。この例のままだと、設定していないものとして扱われます。省略することもでき、その場合はランダムなパスワードが作られてログに書き出されます

方法 2：Docker Compose

用意された compose.yaml を空のフォルダーにダウンロードし、そのフォルダーで起動します。

curl -fLO https://github.com/ThirtyFile/ThirtyFile/releases/latest/download/compose.yaml
docker compose up -d

アカウントと設定は data フォルダーに、ファイルは storage フォルダーに保存されます。どちらも compose.yaml と同じ場所にあります。中身は普通のフォルダーに入った普通のファイルで、スペースごとに 1 つのフォルダーです（ファイルの保存場所）。ファイルを別のディスクや NAS に置くには、compose.yaml の ./storage をそのパスに変えてください。

ThirtyFile は、渡されたフォルダーの所有者を変更します。起動時に data と storage がほかのユーザーの所有になっていると、ThirtyFile はフォルダーとその中身すべての所有者を、自分が動作するユーザー（id 1000、THIRTYFILE_RUN_AS）に変えます。ほかのプログラムや人が使っている既存のフォルダーを storage に指定すると、それらのファイルの所有者も変わります。空のフォルダーを使うか、THIRTYFILE_RUN_AS をそのフォルダーの今の所有者に設定してください。グループ経由で NAS の共有フォルダーにアクセスするには、--group-add 2001（compose.yaml では group_add:）でグループを追加します。ThirtyFile はユーザーを切り替えた後も、そのグループを保持します。

用意された compose.yaml は、ルートファイルシステムを読み取り専用にし、フォルダーの引き渡しとユーザーの切り替えに必要な 4 つを除いて Linux のケーパビリティをすべて外し、no-new-privileges を設定してコンテナーを実行します。Kubernetes など、コンテナーを root で起動できない環境では、そのユーザーで直接実行し（--user 1000:1000、または runAsUser: 1000 と runAsGroup: 1000）、ボリュームの所有者をそのユーザーにしてください。その場合、ThirtyFile は引き渡しを行いません。

管理者のパスワードを自分で決めるには、最初に起動する前に、同じフォルダーに .env という名前のファイルを作り、次のように書きます。

THIRTYFILE_ADMIN_PASSWORD=choose-a-password

サインイン

  1. http://localhost:8080 を開きます。ほかのパソコンからは、localhost の代わりにサーバーのアドレスを使います。
  2. ロック画面のどこかをクリックし、admin と決めたパスワードでサインインします。
  3. 左下のアカウントメニューを開き、パスワードの変更を選びます。
パスワードを設定しなかった場合は？ランダムなパスワードが作られ、ログに書き出されます。docker logs thirtyfile 2>&1 | grep password で確認できます。

停止と起動

docker stop thirtyfile
docker start thirtyfile

Docker Compose の場合は、compose.yaml のあるフォルダーで docker compose stop と docker compose start を使います。
