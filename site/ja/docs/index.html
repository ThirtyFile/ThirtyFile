インストール

ThirtyFile は Docker で動きます。以下の 2 つから選んでください。どちらも約 1 分です。

始める前に

ファイルを保存するコンピューターやサーバーに Docker をインストールします。他は不要です。

方法 1：docker run

docker run -d --name thirtyfile --restart unless-stopped \
  -p 8080:8080 \
  -v /srv/thirtyfile/data:/data \
  -v /srv/thirtyfile/storage:/storage \
  -e THIRTYFILE_ADMIN_PASSWORD='choose-a-password' \
  ghcr.io/thirtyfile/thirtyfile:latest

v0.6.0 以降は Docker Hub にもあります。上のコマンドで thirtyfile/thirtyfile:0.6 を使えばその系列を保持します。Compose の compose.yaml は image: の ghcr.io/thirtyfile/thirtyfile を thirtyfile/thirtyfile に変え、Hub にあるタグと既存ボリュームを維持します。以前のリリースは GHCR にあります。

指定役割
-p 8080:8080アクセスするポート。80 なら -p 80:8080
-v /srv/thirtyfile/data:/dataアカウントと設定の保存先。更新でも保持します
-v /srv/thirtyfile/storage:/storageファイルの保存先。別ディスクや NAS にもできます
THIRTYFILE_ADMIN_PASSWORD最初のアカウントのパスワード。choose-a-password を変更してください。この例は未設定同様に無視します。任意で、未指定はランダム生成してログに書きます

方法 2：Docker Compose

空のフォルダーへ compose.yaml を取得し、そこで起動します。

curl -fLO https://github.com/ThirtyFile/ThirtyFile/releases/latest/download/compose.yaml
docker compose up -d

compose.yaml と同じ場所の data にアカウントと設定、storage にファイルを保存します。スペースごとの通常フォルダーの通常ファイルです（保存先）。別ディスクや NAS なら compose.yaml の ./storage をそのパスに変えます。

指定フォルダーの所有者を変更します。 起動時、所有者が違えば data、storage とその全内容を実行ユーザー（ID 1000、THIRTYFILE_RUN_AS）にします。他プログラムや他人が使う既存フォルダーを storage に指定しても変わります。空を使うか、THIRTYFILE_RUN_AS に既存の所有者を設定してください。NAS のグループでアクセスするなら --group-add 2001（Compose は group_add:）を指定すれば、ユーザー切り替え後も維持します。

配布 Compose はルート FS を読み取り専用にし、所有者変更とユーザー切り替えの 4 権限以外を外し、no-new-privileges を使います。Kubernetes など root 開始不可なら、直接 --user 1000:1000、または runAsUser: 1000、runAsGroup: 1000 で動かし、ボリュームをそのユーザー所有にしてください。所有者変更を省略します。

管理者パスワードを決めるには、初回起動前に compose.yaml と同じ場所の .env に書きます。

THIRTYFILE_ADMIN_PASSWORD=choose-a-password

サインイン

  1. http://localhost:8080 を開きます。別のコンピューターからは localhost をサーバーのアドレスに変えます。
  2. ロック画面をクリックし、admin と指定パスワードで入ります。
  3. 左下のアカウントメニューで パスワードの変更 を選びます。
未設定の場合、ランダム生成してログに書きます。docker logs thirtyfile 2>&1 | grep password で確認します。

停止と起動

docker stop thirtyfile
docker start thirtyfile

Compose なら compose.yaml の場所で docker compose stop と docker compose start を使います。
