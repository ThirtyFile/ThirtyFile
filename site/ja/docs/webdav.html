ネットワークドライブとして割り当て（WebDAV）

ThirtyFile のスペースを、Windows のエクスプローラー、macOS の Finder、WebDAV 対応のモバイルアプリ、rclone から、コンピューターのドライブのように開けます。

アドレスとサインイン

ThirtyFile のアドレスの /dav/ で WebDAV を利用できます。たとえば次のアドレスです。

https://files.example.com/dav/

ユーザー名 と アプリパスワード でサインインしてください。通常のパスワードは使いません。コンピューターやスマートフォンごとに、アカウントメニューの アプリパスワード で作成します。

  • ファイルを操作するには ファイルの読み取りと変更 を選びます。読み取り専用のアプリパスワードは開くこととダウンロードができますが、保存、作成、名前の変更、移動、削除はできません。
  • シングルサインオンのアカウントも、ここではアプリパスワードを使います。
  • 2 段階認証のコードは求めません。誤ったアプリパスワードは通常の上限で数え、同じアドレスから 30 回失敗すると、15 分間待つ必要があります。

表示されるもの

最上位には、利用できるスペースごとに 1 つのフォルダーがあります。

  • マイファイル：個人用スペースがある場合に表示します。
  • 会社のスペース（管理者が名前を変えていなければ すべてのファイル）と、各チームスペースの名前。同名なら後のものに Projects (2) のように番号を付けます。
  • 共有アイテム：自分がメンバーではないスペースから、ほかの人が共有したフォルダーやファイルです。

ブラウザーのアドレスバーに表示するものと同じパスで、そこに入力、貼り付けもできます（パス）。

ブラウザーと同じ規則で動きます。変更できる内容は権限で決まり、読み取り専用スペースは変更できず、容量制限とアップロード上限も適用します。変更はすべてアクティビティログに記録します。ファイルやフォルダーの 削除 はごみ箱への移動で、ブラウザーから復元できます。

Windows

Windows の標準クライアントには WebClient サービスが必要です。Microsoft はこのサービスを非推奨にし、既定では起動しません。利用できるかは Windows の構成と管理者のポリシーによります。割り当てが使えない場合は、専用の WebDAV クライアントか rclone を使ってください。Microsoft の WebClient に関する案内 を参照してください。

  1. エクスプローラーで PC を右クリックし、ネットワークドライブの割り当て を選びます（Windows 11 ではツールバーの …（もっと見る） にあります）。
  2. ドライブ文字を選び、フォルダー に https://files.example.com/dav/ を入力します。
  3. 別の資格情報を使用して接続する をオンにし、完了 を選び、ユーザー名とアプリパスワードを入力します。再起動後も接続するなら 資格情報を記憶する をオンにします。
Windows は HTTPS でのみパスワードを送ります。Windows が信頼する証明書を使い、ThirtyFile を HTTPS の背後 に配置してください。通常の http:// は WebClient サービスのレジストリ値 BasicAuthLevel を変更しなければ拒否され、変更は推奨しません。また既定のファイル上限は 50 MB です（HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters の FileSizeLimitInBytes。最大値は 4 GB）。

macOS

  1. Finder で 移動 › サーバへ接続（⌘ K）を選びます。
  2. https://files.example.com/dav/ を入力し、接続 を選びます。
  3. 登録ユーザ を選び、ユーザー名とアプリパスワードを入力します。必要なら このパスワードをキーチェーンに保存 をオンにします。

Finder のサイドバーの 場所 にドライブとして表示します。Finder は追加情報を持つファイルの横に ._ で始まる隠しファイルを保存します。ブラウザーにも表示し、削除できます。

iPhone、iPad、Android

  • iPhone と iPad：HTTPS の WebDAV に明示的に対応するアプリを使い、アドレス、ユーザー名、アプリパスワードを追加します。ファイルプロバイダーを提供するアプリなら、「ファイル」で有効にして接続を参照できます。「ファイル」標準の サーバへ接続 は SMB サーバー向けで、ThirtyFile の /dav/ に直接接続できません。Apple の ファイルの機能説明 に SMB 対応の説明があります。
  • Android：HTTPS の WebDAV に明示的に対応するファイル管理アプリやクライアントで、アドレス、ユーザー名、アプリパスワードを追加します。SMB、FTP、SFTP の対応だけでは WebDAV クライアントとして使えません。

rclone

rclone は、バックアップなどのためにコマンドラインから ThirtyFile のファイルをコピー、同期します。アプリパスワードをシェル履歴に残さないよう、対話式の設定を使ってください。

rclone config

thirtyfile というリモートを作り、webdav、URL https://files.example.com/dav/、ベンダー other を選び、求められたら ThirtyFile のユーザー名とアプリパスワードを入力します。このユーザー名とパスワードの設定では Bearer トークンを空欄にします。rclone の保存パスワードは難読化されていますが元に戻せるため、設定ファイルを資格情報として保護してください。

その後は、通常の rclone リモートと同じように使えます。

rclone ls "thirtyfile:My files"
rclone copy ~/Pictures "thirtyfile:My files/Pictures" --progress
rclone mount thirtyfile: ~/ThirtyFile --vfs-cache-mode writes

ThirtyFile から 別の場所へのバックアップなど、rclone copy で読み出すだけなら読み取り専用のアプリパスワードで十分です。

接続や保存に失敗する場合

  • 401、パスワードを繰り返し求められる：ユーザー名とアプリパスワードを使ってください。ブラウザー用パスワード、メールアドレス、2 段階認証コードは使いません。有効期限、失効、アカウントが有効かを確認します。何度も失敗した後は 15 分待ってください。
  • 読めるが保存できない：アプリパスワードの書き込み範囲、スペースの権限、容量制限、保存場所の読み取り専用やオフライン状態を確認します。
  • 404、サインインの Web ページ、予期しないリダイレクト：完全な /dav/ アドレスを使い、リバースプロキシに WebDAV メソッドと Authorization ヘッダーを転送させます。HTML のサインインページは WebDAV の応答ではありません。
  • 証明書や大きなファイルのエラー：信頼できる証明書で HTTPS を使います。クライアントの転送上限と、プロキシのサイズ上限、タイムアウトを確認します。ブラウザーはチャンク送信、WebDAV は 1 リクエストで全ファイルを送信します。

知っておきたいこと

  • 各ファイルを一度に送信します。リバースプロキシは大きなリクエストを許可する必要があります。インターネットに公開 を参照してください。
  • 名前はブラウザーと同じ規則です。Windows で使えない文字（\ / : * ? " < > |）は拒否します。
  • Office などは開いている間にファイルをロックします。ThirtyFile は保存が動くようにロック要求に応答しますが、ロックを強制しません。2 人が同時に保存すると、最後の内容が残ります。共同作業にはブラウザーのオンラインエディターを使ってください。
  • サーバー上のフォルダー（フォルダースペース）も使えます。変更はそのフォルダー内で行い、サーバーで追加されたファイルはフォルダーを開くと表示します。
  • サーバー上のフォルダーとの間で大きなフォルダーを移動、コピーすると、ファイルをコピーします。完了してから応答しますが、1 分以上かかる場合は受付済みと応答し、アプリが待つのをやめたり接続が切れたりしてもバックグラウンドで完了します。少し待って結果を確認してください。
  • 共有されたアイテムを自分のスペースへ移動することは、ブラウザーと同様にできません。コピーしてください。
  • フォルダーは 1 階層ずつ一覧表示します。全ツリーを一度に求めるクライアントには、フォルダーごとに要求するよう応答します。一般的なクライアントはすべて対応しています。
