單人模式

把 ThirtyFile 當成沙盒裡給一個人用的檔案管理員：不用登入、沒有帳號，只管理一個資料夾。

有哪些不同

單人模式適合只有你能連到的地方：沙盒、虛擬機器，或在自己電腦上執行的容器。開啟網頁，檔案就在眼前。它預設關閉，必須明確開啟，而且不影響一般伺服器。

  • 不用登入。連到網頁的人都是同一個人。沒有帳號、密碼或兩步驟驗證碼。
  • 一個資料夾。檔案就是你選的資料夾（THIRTYFILE_FILES）裡的一般檔案。可以瀏覽、上傳、下載、建立、編輯、重新命名、移動與刪除，預覽、搜尋、標籤、資源回收筒與編輯器都和平常一樣。在資料夾外面做的變更也會顯示出來。
  • 多人才需要的功能都沒有。使用者與群組、權限、分享連結、訪客、控制台、通知、WebDAV、S3 儲存貯體與 FTP 接收資料夾不只是隱藏，而是直接關閉：伺服器不會回應它們。SFTP 也保持關閉。
  • 只動那個資料夾。伺服器只在該資料夾內讀寫。資料夾內指向外面的連結會被略過，和所有資料夾空間一樣。

用 Docker 執行

docker run -d --name thirtyfile --restart unless-stopped \
  -p 127.0.0.1:8080:8080 \
  -v /srv/thirtyfile/data:/data \
  -v /srv/work:/files \
  -e THIRTYFILE_SINGLE_USER=true \
  -e THIRTYFILE_FILES=/files \
  -e THIRTYFILE_RUN_AS=1000:1000 \
  ghcr.io/thirtyfile/thirtyfile:latest
部分作用
-p 127.0.0.1:8080:8080只在這台電腦上開放網頁。少了 127.0.0.1:，Docker 會繞過防火牆，把連接埠開放給電腦所在的每個網路
-v /srv/work:/files要管理的資料夾。請掛載沙盒內的某個資料夾，不要掛載更大的範圍：伺服器能動到的就只有它
THIRTYFILE_SINGLE_USER=true開啟單人模式
THIRTYFILE_FILES=/files資料夾在容器內的路徑。必填
THIRTYFILE_RUN_AS=1000:1000伺服器使用的使用者。它必須能修改 /files 內的檔案：請使用該資料夾擁有者的編號（id -u 與 id -g）

/data 資料夾保存索引、縮圖與設定。它不能位在檔案資料夾裡面，而且只屬於這個模式：在單人模式建立的資料夾無法啟動一般伺服器，反過來也一樣。之後改選別的資料夾，就會改顯示那個資料夾；舊的資料夾保持原樣。

從你的電腦連線

在容器內，伺服器監聽所有位址，而 Docker 只會轉送你發布的連接埠。使用 -p 127.0.0.1:8080:8080 時，在執行 Docker 的電腦上開啟 http://localhost:8080。不用 Docker 時，伺服器預設只監聽 127.0.0.1:8080（可用 THIRTYFILE_ADDR 更改）。

當沙盒是另一台機器或虛擬機器時，從你的電腦轉送連接埠，網頁到達時仍然是 localhost：

ssh -L 8080:127.0.0.1:8080 user@sandbox

然後在你的電腦上開啟 http://localhost:8080。許多沙盒與開發容器有連接埠轉送設定，效果相同。

伺服器只回應 localhost、127.0.0.1 與 [::1]。用其他名稱連來的網頁會看到「unknown host name」。當轉送工具或代理伺服器替網頁取了自己的名稱，請把它列出來：

-e THIRTYFILE_ALLOWED_HOSTS=sandbox.example.com

誰能連到它

這裡沒有登入，所以只要連得到連接埠，就能取得資料夾內的所有檔案。擋住其他人的是沙盒與周圍的網路，而不是 ThirtyFile。請讓連接埠只在本機位址上，或放在你自己的轉送後面，不要發布到其他網路或網際網路。啟動時，若監聽的位址不是本機位址，ThirtyFile 會在紀錄中寫下警告；在 Docker 內這是正常的，重要的是發布出去的連接埠。

因為你瀏覽的網站可以對 localhost 送出請求，ThirtyFile 仍然會做這些事：

  • 瀏覽器表示來自其他網站的請求會被拒絕，Origin 不是網頁本身的變更也一樣。
  • 使用不是這台電腦名稱的請求會被拒絕，這能擋下讓自己的名稱指向你電腦的網站（DNS 重新綁定）。
  • 只能存取所選資料夾之下的檔案。

同一台電腦上的程式仍然可以使用該連接埠。若電腦上有不信任的程式，請把沙盒的網路與它們隔開。

設定

變數預設值作用
THIRTYFILE_SINGLE_USERfalse開啟單人模式
THIRTYFILE_FILES要管理的資料夾的完整路徑。此模式必填，且不能包含資料資料夾或位在其中
THIRTYFILE_ADDR127.0.0.1:8080伺服器監聽的位址（一般伺服器是 0.0.0.0:8080；Docker 映像檔自己會設定）
THIRTYFILE_ALLOWED_HOSTS除了 localhost 之外，網頁可以使用的名稱，以逗號分隔

其他設定，例如 THIRTYFILE_TRASH_DAYS 與 THIRTYFILE_MAX_UPLOAD_MB，和設定中的說明相同。備份、儲存位置等是控制台的功能，這裡沒有：請直接複製資料夾，或使用沙盒本身的快照。

改回一般伺服器

用新的資料資料夾啟動一般伺服器，再把該資料夾加成空間。你的檔案從來不在資料資料夾裡，所以不需要匯出。
