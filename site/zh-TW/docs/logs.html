紀錄

開啟控制台 › 活動紀錄。

紀錄紀錄內容
活動上傳、編輯、遷移、刪除、分享和設定變更
分享連結存取誰打開了連結、密碼嘗試、預覽和下載
登入成功與失敗的登入、登出（包括從裝置中讓裝置登出）、修改密碼、兩步驟驗證（錯誤驗證碼、使用復原碼、開啟、關閉或重設），以及應用程式密碼的建立、移除和錯誤密碼嘗試
錯誤使用者遇到的錯誤：伺服器無法完成的請求，以及網頁發生的錯誤（頁面異常，上傳、預覽或檔案操作失敗）

可按人員、操作和日期篩選，並將結果匯出為 Excel 能開啟的 CSV 檔案。匯出檔案使用頁面中看到的名稱、語言和你的時區。

管理員可以檢視活動紀錄；空間管理者可從空間屬性（此電腦）檢視對應空間的紀錄。其他人可以在可存取檔案或資料夾的詳細資料窗格檢視近期活動。

其他人的個人空間紀錄會說明誰在何時做了什麼，但不顯示具體檔案或資料夾：項目名稱和詳細資訊會省略（參閱管理員能看到什麼）。搜尋、CSV 匯出、個人空間分享連結的存取紀錄，以及封存檔也遵守相同規則。

所有人都可以從帳號選單檢視自己的登入紀錄和已登入裝置。參閱你的帳號。

錯誤

錯誤分頁僅供管理員使用。每筆紀錄顯示發生時間、遇到錯誤的人（或未登入）、來源和當時的操作。按一下時間可檢視詳細資訊：錯誤類型、請求狀態、請求 ID、版本，以及網頁錯誤的呼叫堆疊。

  • 伺服器紀錄表示伺服器回傳錯誤的請求。意外失敗（資料庫或儲存問題、請求耗時過長）屬於錯誤；被拒絕的變更（名稱已存在、沒有權限、檔案過大）屬於警告。可按嚴重程度篩選。
  • 網頁記錄由頁面傳送：頁面異常、未攔截的 JavaScript 錯誤，以及上傳、預覽、儲存和檔案操作時顯示的失敗。
  • 網頁報告伺服器已記錄的失敗請求時，兩者會透過請求 ID 合併為一筆紀錄，網頁顯示的內容列在網頁報告下。
  • 10 分鐘內再次出現相同錯誤時，只增加原記錄的次數，不新增紀錄。報告還按人員和分鐘限流，避免迴圈報錯的網頁填滿紀錄。
  • 檔案與資料夾名稱不會記錄：引號中的文字替換為 "…"（或 「…」）；網頁報告伺服器的英文訊息，而非譯文；請求按路由記錄（PATCH /api/nodes/{id}），不會記錄實際請求的路徑。密碼、cookie、分享連結權杖和檔案內容永遠不會紀錄。完整伺服器故障資訊可在伺服器紀錄（docker logs）中用同一請求 ID 找到。

紀錄保留時間

在控制台 › 紀錄設定中：

  • 活動和分享連結存取記錄保留 180 天，登入記錄保留 365 天。錯誤記錄與活動記錄保留相同時間。
  • 較舊記錄移入壓縮封存檔，保留 3 年，可從同一頁面下載。封存檔每行包含一筆 JSON 紀錄，使用紀錄內部代碼（upload、bad_password），時間為自 1970 年起的秒數（UTC），不因顯示語言改變。
  • 可關閉訪客 IP 位址和瀏覽器的紀錄。
紀錄包含 IP 位址，在許多國家屬於個人資料。請按照自己的隱私政策保留和刪除。

品牌

開啟控制台 › 品牌。

  • 名稱與標誌，可為深色模式另設一個標誌。標誌也用作瀏覽器分頁圖示。
  • 淺色和深色模式的顏色。
  • 外觀：淺色、深色或跟隨個人裝置，以及是否允許使用者自行更改。
  • 登入畫面：背景圖片、文字，以及是否顯示鎖定畫面。
