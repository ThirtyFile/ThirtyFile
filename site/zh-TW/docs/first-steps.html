初次設定

第一次登入後要設定的四件事。全都在控制台裡，位於左側選單的最下方。

安裝與初次設定這兩篇指南有繁體中文版，其他指南目前只有英文版。

1. 網站網址與語言

開啟控制台 › 一般。

  • 網站網址：大家用來連到網站的位址，例如 https://files.example.com。分享連結是以它產生的，所以請在分享任何東西之前先設定好。
  • 預設語言：英文、繁體中文，或依照每個人的瀏覽器語言。使用英文時，日期、時間與數字會依瀏覽器設定的地區顯示：例如瀏覽器設為英文（英國）時，會顯示「日/月/年」與 24 小時制的時間。
  • 個人空間：新使用者是否擁有自己的「我的檔案」、放在哪個儲存位置，以及最多可以存放多少資料。請參閱個人空間。
  • 兩步驟驗證與密碼最短長度。請參閱登入安全性。

2. 檔案存放在哪裡

除非另外指定，檔案會以一般資料夾的形式存放在 storage 資料夾中：「全部檔案」在 company，其他則在 teams/<空間名稱> 與 users/<使用者名稱>（請參閱檔案存放在哪裡）。若要改用 NAS、S3、SFTP 或 FTP，請開啟控制台 › 儲存位置，新增位置後設為預設。

各種類型的細節，請參閱儲存位置。

3. 人員

在控制台 › 使用者建立帳號，在群組中把人員分組，例如每個部門一個群組。

如果你的組織使用 Microsoft、Google 或 GitHub 帳號，或有自己的身分識別服務（任何 OpenID Connect 服務，例如 Keycloak 或 Authentik），大家就能用這些帳號登入。請參閱單一登入。

4. 你的名稱與標誌

在控制台 › 品牌設定網站名稱、標誌、色彩，以及登入畫面上的圖片。
