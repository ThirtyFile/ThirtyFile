連線為網路磁碟機（WebDAV）

透過 Windows 檔案總管、macOS Finder、支援 WebDAV 的手機 App或 rclone 開啟 ThirtyFile 空間，就像使用電腦上的磁碟機一樣。

位址與登入

ThirtyFile 在自身位址的 /dav/ 路徑提供 WebDAV，例如：

https://files.example.com/dav/

請使用帳號和應用程式密碼登入，不要使用帳號登入密碼。在帳號選單的應用程式密碼中，為每台電腦或手機分別建立一個：

  • 如需處理檔案，選擇讀取並變更檔案。唯讀應用程式密碼可開啟和下載檔案，但不能儲存、建立、重新命名、移動或刪除任何項目。
  • 透過單一登入存取的帳號在這裡也使用應用程式密碼。
  • 這裡不會要求兩步驟驗證碼。錯誤應用程式密碼會計入一般限制：同一位址失敗 30 次後，該位址必須等待 15 分鐘。

目錄內容

頂層目錄為每個可存取空間提供一個資料夾：

  • 我的檔案：你的個人空間（如果有）。
  • 公司空間（除非管理員改名，否則為全部檔案），以及按名稱顯示的團隊空間。兩個空間同名時，後一個會加上數字，例如 Projects (2)。
  • 與我共用：別人從你不是成員的空間中向你分享的資料夾與檔案。

這些路徑與瀏覽器位址列顯示的相同，也可以在瀏覽器中輸入或貼上（參閱路徑）。

所有行為與瀏覽器一致：能否更改取決於權限，唯讀空間不能修改，空間儲存上限和上傳大小限制同樣適用，每次變更都會出現在活動紀錄中。刪除檔案或資料夾會移入資源回收筒，可在瀏覽器中還原。

Windows

Windows 內建用戶端需要 WebClient 服務。Microsoft 已棄用該服務，預設不啟動；是否可用取決於 Windows 安裝和管理員規則。無法對映磁碟機時，請使用專用 WebDAV 用戶端或 rclone。參閱 Microsoft 的 WebClient 公告。

  1. 在檔案總管中右鍵按一下此電腦，選擇對映網路磁碟機（Windows 11 中位於工具列的 …（檢視更多））。
  2. 選擇磁碟機代號，在資料夾中填寫位址：https://files.example.com/dav/
  3. 勾選使用其他認證資訊連線，按一下完成，輸入使用者名稱與應用程式密碼。勾選記住我的認證資訊即可在重新啟動後重新連線。
Windows 只透過 HTTPS 傳送密碼。ThirtyFile 需要透過 HTTPS 提供服務，並使用 Windows 信任的憑證；一般 http:// 位址會被拒絕，除非修改 WebClient 服務的登入檔值 BasicAuthLevel，但不建議這樣做。Windows 預設還限制檔案大小為 50 MB（位於 HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters 的 FileSizeLimitInBytes，最大值為 4 GB）。

macOS

  1. 在 Finder 中選擇前往 › 連線伺服器（⌘ K）。
  2. 輸入 https://files.example.com/dav/，按一下連線。
  3. 選取註冊使用者，輸入使用者名稱與應用程式密碼。可以勾選在我的鑰匙圈中記住此密碼。

空間會作為磁碟機顯示在 Finder 側欄的位置下。Finder 會在帶有額外資訊的檔案旁建立以 ._ 開頭的隱藏檔案；這些檔案也會顯示在瀏覽器中，可以刪除。

iPhone、iPad 與 Android

  • iPhone 與 iPad：使用明確支援透過 HTTPS 存取 WebDAV 的 App，在 App 中新增位址、使用者名稱與應用程式密碼。如果 App 提供「檔案」擴充套件，可在「檔案」App 中啟用，然後瀏覽該連線。「檔案」內建的連線伺服器用於 SMB 伺服器，不能直接連線 ThirtyFile 的 /dav/ 端點。Apple 的「檔案」功能說明介紹了 SMB 支援。
  • Android：使用明確支援 HTTPS WebDAV 的檔案管理器或用戶端，新增位址、使用者名稱與應用程式密碼。僅支援 SMB、FTP 或 SFTP 不代表該 App 是 WebDAV 用戶端。

rclone

rclone 可透過命令列與 ThirtyFile 複製和同步檔案，例如用於備份。請使用互動式設定，避免應用程式密碼被寫入 shell 歷史：

rclone config

建立名為 thirtyfile 的 remote，選擇 webdav，URL 設為 https://files.example.com/dav/，vendor 選擇 other，然後按提示輸入 ThirtyFile 使用者名稱與應用程式密碼。採用此使用者名稱/密碼方式時，bearer token 留空。rclone 會混淆儲存的密碼，但這種混淆可以逆向還原：請像保護認證資訊一樣保護設定檔案。

然後可以像其他 rclone remote 一樣使用：

rclone ls "thirtyfile:My files"
rclone copy ~/Pictures "thirtyfile:My files/Pictures" --progress
rclone mount thirtyfile: ~/ThirtyFile --vfs-cache-mode writes

使用 rclone copy 從 ThirtyFile 複製檔案時，唯讀應用程式密碼就足夠，例如將檔案備份到其他位置。

連線或儲存失敗時

  • 401 或不斷要求輸入密碼：使用使用者名稱與應用程式密碼，不要使用瀏覽器登入密碼、電子郵件位址或兩步驟驗證碼。檢查應用程式密碼是否過期或被撤銷，以及帳號是否啟用。失敗次數過多後，請等待 15 分鐘再嘗試。
  • 能讀取但不能儲存：檢查應用程式密碼的寫入權限、空間中的權限、儲存上限，以及儲存位置是否唯讀或離線。
  • 404、登入網頁或意外重新導向：使用完整的 /dav/ 位址，並設定反向代理轉發 WebDAV 方法和 Authorization 請求標頭。HTML 登入頁不是 WebDAV 回應。
  • 憑證或大檔案錯誤：使用 HTTPS 和受信任憑證。同時檢查用戶端傳輸限制、代理請求大小限制和逾時設定。瀏覽器上傳使用分段，WebDAV 則透過單次請求傳送完整檔案。

注意事項

  • 每個檔案一次完整傳送。ThirtyFile 位於反向代理後方時，代理必須允許大型請求通過：參閱從網際網路存取。
  • 名稱規則與瀏覽器相同：Windows 不允許的字元（\ / : * ? " < > |）會被拒絕。
  • Office 等程式在開啟檔案時會加鎖。ThirtyFile 會回應這些鎖請求以便儲存，但不會強制執行鎖：兩人同時儲存同一檔案時，最後儲存者的內容生效。共同處理檔案時請使用瀏覽器中的線上編輯器。
  • 伺服器資料夾（資料夾空間）也可使用：變更直接寫入資料夾本身，伺服器新增的檔案會在開啟資料夾時顯示。
  • 將大資料夾移入或移出伺服器資料夾時，需要複製其中的檔案。ThirtyFile 在完成後回應；如果超過一分鐘，會回覆變更已被接受並繼續在背景完成，即使用戶端已停止等待或斷開連線。稍後重新檢視即可確認結果。
  • 與瀏覽器一樣，不能將別人分享給你的項目移動到自己的空間；請改用複製。
  • 每次只列出資料夾的一層；請求一次列出整棵目錄樹的用戶端會收到逐資料夾查詢的要求，常見用戶端都採用這種方式。
