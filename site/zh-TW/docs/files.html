檔案操作

ThirtyFile 的操作方式類似檔案總管；使用Mac 風格時則類似 Mac 的 Finder。本頁介紹可用操作與加快操作的快捷鍵。

導覽介面

  • 左側選單：最近使用的檔案、我的最愛、空間、與你分享的項目、分享連結、資源回收筒、你的智慧型資料夾與標籤。
  • 分頁：同時開啟多個資料夾或檔案。按 + 新增分頁，或以滑鼠中鍵按資料夾，在新分頁開啟。
  • 位址列：顯示所在位置。按路徑任一部分即可前往；按路徑旁空白處（或 Ctrl + L）可查看完整路徑、複製路徑，或輸入／貼上另一個路徑後按 Enter 前往（參閱路徑）。
  • 搜尋：在目前資料夾與子資料夾中尋找名稱包含輸入文字的項目（從最近使用、我的最愛等清單搜尋時，範圍是所有可存取位置）。所有語言都不區分大小寫；輸入三個以上字元時也不區分重音符號。結果頁可擴大範圍到所有位置，並依類型、修改日期、大小與標籤篩選。最多顯示 300 筆，超過時會提示。儲存為智慧型資料夾可保留搜尋條件（參閱智慧型資料夾）。
  • 檢視：選擇清單呈現方式（參閱檢視、欄位與群組）。右下角兩個按鈕可切換詳細資料與大圖示。

最近使用依新到舊列出你上傳、編輯或開啟的檔案，不論位於自己的空間或共用空間／資料夾。開啟是指在瀏覽器檢視（檢視器、編輯器或預覽窗格）；下載與使用應用程式密碼的檔案用戶端不計入。無法再開啟或已在資源回收筒的檔案會略過。

大型資料夾

數千個項目的資料夾會立即顯示第一批項目，之後按需載入你捲動到、以 End／Page Down 前往，或拖曳捲軸到的部分。尚未載入的列短暫顯示灰線，狀態列顯示正在載入更多項目…。狀態列計算資料夾全部項目，包括尚未載入的。只有附近部分保留在記憶體，因此十萬個項目也不會拖慢瀏覽器。

選取可涵蓋整個資料夾，包括尚未載入的項目：

  • Ctrl + A（或全選）選取資料夾全部項目。Ctrl + 按一下可取消個別項目；狀態列顯示選取數量。
  • Shift + 按一下，或 Shift + End，會選取兩個項目之間的全部內容，不論距離多遠。
  • 搬移、複製、剪下貼上、拖曳、加入我的最愛、標籤、移到資源回收筒與永久刪除，都會處理全部選取項目。ThirtyFile 每次處理一千個，底部訊息顯示進度；這類大型變更無法從訊息復原。
  • 一次下載或建立 ZIP 最多處理 10,000 個項目；更多時請下載資料夾本身。
  • 詳細資料窗格顯示選取數量；選取整個資料夾時會顯示總大小。

輸入名稱開頭會跳到已載入項目中下一個符合的項目。向上（或返回）回到大型資料夾時，無論原資料夾在清單何處，都會顯示並選取它。依日期或類型分組（見下方）會載入整個資料夾，確保每個群組完整。

檢視、欄位與群組

檢視選單包含檔案總管的各種檢視，以及直欄：

  • 大圖示與中圖示：圖片、PDF 與影片縮圖（參閱縮圖），名稱顯示在下方。
  • 清單：小圖示與名稱並排分欄，便於一次查看許多項目。
  • 詳細資料：每列一個項目，附各欄位。
  • 並排：縮圖旁顯示名稱、類型與大小。
  • 直欄：從空間頂層到目前資料夾，每層各有一欄。選取資料夾會在右側下一欄顯示內容；選取檔案會顯示預覽欄，包含圖片、類型、大小、日期及開啟、下載、分享按鈕。手機本來就一次顯示一個資料夾，因此不提供此檢視。

在直欄中，↑／↓在欄內移動，→進入所選資料夾的欄，←返回前一欄；輸入名稱開頭可跳到項目。按其他欄的項目會前往該欄。返回時會保留右側已開啟的欄，直到另選項目。選取、開啟、重新命名與刪除和其他檢視相同，大型資料夾也會分批載入；可將項目拖到任何欄的資料夾，或另一欄的空白處以搬移。拖曳欄右邊緣可調整寬度（連按兩下恢復預設）；寬度會在此瀏覽器保留到登出。分組依據不適用此檢視。

沒有縮圖的檔案顯示類型圖示。程式語言與資料格式各有專屬圖示（JSON、Rust 與 Go 不同）；常見工具檔案即使沒有副檔案名稱，也可依名稱辨識：Dockerfile、Makefile、.env、.gitignore、package.json、鎖定檔、LICENSE 與 README。字型、磁碟映像、安裝程式、資料庫、電子書、設計檔、3D 模型與憑證也有圖示。在詳細資料將游標移到類型欄可查看檔案種類。無法辨識的檔案維持一般檔案圖示。

在詳細資料中，拖曳欄位標題邊緣可調寬度（或用 Tab 選取邊緣後以方向鍵調整）；連按兩下邊緣恢復預設。右鍵按欄位標題，或選擇檢視 › 欄位，可選擇修改日期、建立日期（預設隱藏）、類型、大小、標籤（預設隱藏），以及清單適用時的位置與上傳者。還原預設欄位可復原調整。清單太窄而容不下全部欄位時（例如開啟詳細資料窗格），會先隱藏類型再隱藏大小，之後才橫向捲動。手機只顯示名稱與大小。

排序可依名稱、修改日期、建立日期、類型或大小，由 A 到 Z 或反向排列；按欄位標題也相同。資料夾永遠在前。名稱排序類似檔案總管：不區分大小寫，數字依數值排序（File 2 在 File 10 前）。其他字元依 Unicode 碼位排序，因此中文與日文依 Unicode 順序（平假名、片假名、漢字），不是讀音或筆畫。所有語言與使用者的順序一致，讓大型資料夾分頁載入不會遺漏或重複。

檢視 › 分組依據會將項目分組，各組標題附項目數：

  • 類型：資料夾在前，其餘每種檔案類型各一組。
  • 修改日期：今天、昨天、本週稍早、上週、本月稍早、上個月、今年稍早與很久以前（每週從星期一開始）。

組內仍依清單排序。若按相同依據反向排序（舊到新，或類型 Z 到 A），群組順序也會反向。檢視、欄位與分組設定會在瀏覽器中對每個資料夾保留。

路徑

路徑在位址列與 WebDAV 中都用相同方式表示資料夾或檔案，從包含所有空間的頂層開始，例如 /My files/Reports/2026.xlsx：

  • / 是所有空間。
  • 我的檔案是個人空間（管理員可能未提供）。公司空間（全部檔案，除非管理員改名）與團隊空間使用各自名稱。同名時後建立者加上編號，例如專案 (2)，WebDAV 使用相同編號。
  • 與我共用包含其他人從你不是成員的空間分享的資料夾與檔案：/Shared with me/Plans/Q1。同名分享項目也會編號。

ThirtyFile 提供的名稱（我的檔案、全部檔案、與我共用）依所選語言顯示，輸入路徑時可使用該語言或英文。不區分大小寫，\ 等同 /，也可貼上 WebDAV 位址或 ThirtyFile 頁面連結。路徑不存在或無權存取時，位址列會提示並保留輸入供修正。最近使用、我的最愛、資源回收筒等清單不在空間中，因此不能輸入其路徑。

管理員也可輸入控制台路徑：/Control panel/Storage locations，或所選語言中顯示的名稱。從控制台位址列複製的路徑也可使用。若需要不受語言影響的路徑，可用 /admin、/admin/storage、/admin/usage 或其他控制台頁面位址。Windows 位址列與 Mac 風格的前往資料夾都支援。所需管理員權限和從選單開啟相同。辨識到的控制台路徑優先於同名空間；請從側欄開啟該空間，或貼上其完整頁面 URL。

上傳

  • 把電腦上的檔案或整個資料夾拖入清單。放到清單、資料夾樹、位址列或分頁中的資料夾，可上傳到該資料夾；也可以
  • 按新增，選擇上傳檔案或上傳資料夾。

右下角顯示進度，每個檔案會立即開始傳送。超過 100 個檔案時，只列出傳送中、暫停與失敗的，其餘在下方顯示數量。右鍵按清單可一次重試所有失敗檔案。上傳未完成時，瀏覽器會在關閉或重新載入頁面前詢問。無法讀取的拖入項目（沒有權限或已移除）會略過，訊息顯示數量。

傳輸開始前顯示正在準備上傳…。所有位元組傳完後，正在完成上傳…會一直顯示到伺服器確認儲存完成。這兩個階段使用等待指示，沒有完成百分比；仍可暫停與取消。

兩分鐘未收到上傳資料時，伺服器停止等待，上傳可從已收到的位元組繼續。持續傳送資料的長時間上傳沒有總時限。WebDAV 使用相同閒置限制，但失敗的 WebDAV 請求必須完整重送。

中斷的上傳

上傳期間重新載入頁面或關閉分頁／瀏覽器，下次在同一瀏覽器開啟 ThirtyFile 時，右下角中斷的上傳會依原加入方式顯示：資料夾以名稱顯示，一起選取的檔案為同一筆。瀏覽器無法自行重開你的檔案，因此請再次選取：

  • 繼續會要求相同檔案（資料夾則選相同資料夾）。各檔案依伺服器已保存進度繼續，使用同一目標資料夾與同名衝突處理選項。繼續前會檢查整份檔案，包括大小與日期未變的內容變更；大檔案讀取可能需要時間。此檢查會在原上傳傳送時讀取檔案，因此尚未讀完整就中斷的檔案，以及舊版本保存的上傳，都會重新開始。可以繼續表示伺服器仍保有已傳送內容，否則從頭開始。
  • 檔案先依資料夾路徑與名稱配對，再要求大小、日期與內容和原先一致。期間修改或被同名檔案取代的會重新開始，不會接到舊片段。選到不屬於原上傳的檔案會略過，未選到的中斷檔案繼續等待。
  • 伺服器在中斷前剛完成的檔案不會上傳兩次。若伺服器已無法辨識先前完整傳送的檔案，清單會提示可能已上傳；重試前請檢查資料夾。
  • 重新開始會從頭上傳所選檔案，捨棄會移除工作及伺服器已收到的部分。

其他分頁仍在執行的上傳不會提供恢復，只有該分頁關閉後才會出現。中斷上傳在此瀏覽器保留七天，只屬於你的帳號（訪客則屬於其上傳使用的分享連結）。只保存檔案名稱、資料夾、大小、日期與伺服器上傳位址（訪客也包含分享連結），不保存檔案內容。登出會移除這些紀錄。

下載

選取一個或多個項目，按下載。多個項目或資料夾會合成一個 ZIP，內容反映下載開始時的狀態，期間新增到資料夾的項目不會包含。若伺服器資料夾內的檔案在傳送 ZIP 時大小改變，下載會失敗，而不是傳回不完整內容；請重新開始。

右下角顯示進度。超過 256 MB（手機與平板為 64 MB）的下載會直接進入瀏覽器自己的下載清單，避免頁面把內容放在記憶體。

準備下載連結或等待伺服器回應時，顯示正在準備下載…，等待期間可取消。大小未知時，以等待指示取代百分比，但仍顯示已收到的位元組數。準備失敗可重試。直接交給瀏覽器的下載（包含公開分享下載）會提示到瀏覽器下載清單追蹤進度。

一次最多下載 10,000 個所選項目。更多時請下載所在資料夾；無論內容多少，一個資料夾只算一個項目。

壓縮與解壓縮 ZIP

  • 壓縮：選取項目，右鍵選壓縮為 ZIP 檔案，旁邊會出現以項目命名的 ZIP（多個項目則以所在資料夾命名），像一般檔案計入空間用量。壓縮前，ThirtyFile 會確認所選項目的完整大小能容納於空間配額與資料目錄的可用容量，因為 ZIP 在資料目錄組合。
  • 解壓縮：右鍵按 ZIP，選全部解壓縮。內容放到旁邊以 ZIP 名稱命名的新資料夾，名稱已占用時加編號。

兩者都在伺服器執行，底部訊息顯示進度，期間可繼續工作，活動紀錄也會紀錄。

為避免單一檔案耗盡伺服器，符合以下條件的 ZIP 不會解壓縮：

  • 內容超過空間可用容量，或大於 16 GB；
  • 檔案與資料夾超過 20,000 個，包含路徑經過的中間資料夾；
  • 內部路徑超過 64 層資料夾；
  • 內容膨脹遠高於一般檔案（超過壓縮大小 250 倍），例如「ZIP 炸彈」；
  • 內部名稱導向新資料夾之外（../ 或完整路徑），或名稱不允許（例如含 : 或 ?）；
  • 有密碼保護，或使用一般 deflate 以外的壓縮方法。

整理

  • 新增資料夾或文字文件：按新增、用 Ctrl + Shift + N 建資料夾，或右鍵按空白處選新增。和檔案總管相同，項目立即出現在清單末尾，名稱可直接輸入；命名後仍留在末尾，直到重新整理（F5）、變更排序或離開資料夾。建立失敗時會移除並提示原因。
  • 選取：按項目。按住 Ctrl 加選，Shift 選範圍，或拖曳框選。
  • 搬移：拖到資料夾、剪下貼上，或右鍵選搬移到…。可放到清單或資料夾樹的資料夾（停在未展開資料夾上片刻可展開）、位址列路徑片段或資料夾分頁。搬移到…視窗中的新增資料夾會在目前查看的資料夾內建立並開啟新資料夾。
  • 複製：拖放時按住 Ctrl（Mac 為 Option）、複製貼上，或右鍵選複製到…。
  • 重新命名：按 F2，或和檔案總管一樣按已選項目的名稱，稍候即可編輯（連按兩下則開啟）。資料夾樹可按目前開啟資料夾的名稱。Enter 保留新名稱，Esc 保留舊名稱。
  • 右鍵按項目可使用其他功能。和 Windows 11 類似，選單頂部是一排剪下、複製、重新命名、分享與刪除按鈕（游標停留可查看名稱），下方依序有開啟、下載、壓縮、我的最愛、標籤、分享連結、搬移到、複製到與內容。
  • 右鍵按清單空白處可使用檢視、排序依據、分組依據（與工具列相同）、復原（名稱反映操作，例如復原刪除）、重新整理、貼上、新增 › 資料夾或文字文件、上傳 › 檔案或資料夾，以及內容。

移入或移出伺服器上的資料夾會複製檔案，大型資料夾可能需要時間。底部訊息顯示進度，期間可繼續工作；關閉頁面後伺服器仍會接續搬移或複製。

搬移、重新命名或刪除後，底部訊息會短暫提供復原按鈕，將項目移回、還原舊名或從資源回收筒還原。在清單按 Ctrl + Z 也會復原最近一次這類操作。

標籤

標籤是加在檔案與資料夾上的彩色標記，例如緊急或發票，方便之後尋找。一個項目可以有多個標籤。

  • 為項目加標籤：右鍵選標籤，再選標籤。勾號表示所有選取項目都有，橫線表示只有部分有；選橫線會加到全部項目，選已勾選者會移除。新增標籤…會建立並加到項目。詳細資料窗格的編輯標籤可對單一項目做相同操作。
  • 查看標籤：名稱後以彩色圓點顯示，游標停留可讀取名稱。詳細資料窗格依名稱列出，詳細資料檢視的標籤欄也一樣。
  • 尋找標記項目：按左側標籤下的標籤，列出所有位置含該標籤的項目。搜尋結果也可依標籤篩選。
  • 修改標籤：右鍵按左側標籤（或用清單上方工具列）可改名、換色或刪除。刪除會從所有項目移除標籤，項目本身不受影響。標籤旁的 + 可新增。

標籤只屬於你。其他人看不到標籤、名稱與套用項目，共用空間內也一樣；管理員與分享連結訪客也看不到。每個人都可為有權開啟的項目加上自己的標籤。項目重新命名、搬移（包含跨空間）、移入資源回收筒及還原，或被其他程式在伺服器資料夾修改時，標籤仍保留；你建立的副本也繼承原標籤。無權再開啟項目後不再顯示其標籤；永久刪除項目會移除標籤。與分享連結相同，標籤保存在資料庫：備份 data 資料夾會保留，檔案備份不會。

智慧型資料夾

智慧型資料夾是保留的搜尋條件，像資料夾顯示在左側選單，每次開啟都列出當時符合條件的項目，例如最近 30 天修改的 PDF或所有標為緊急的項目。

  • 建立：搜尋並使用篩選條件，按儲存為智慧型資料夾。命名並確認條件後按建立。左側智慧型資料夾旁的 + 可從空白條件建立。
  • 搜尋條件：名稱片段；檔案、資料夾或類型（文件、圖片或自行輸入副檔案名稱）；修改日期（今天、最近 7／30 天或一年，每次開啟重新計算，或兩個日期之間）；大小（預設範圍或兩個大小之間）；你的標籤（同時含所有勾選標籤）。範圍可為資料夾及子資料夾、一個空間，或所有有權存取的位置。
  • 開啟：按智慧型資料夾下的項目。清單附各項目位置，可像一般資料夾排序、分組、選取、開啟、改名、搬移、分享、加標籤與刪除。大量結果和大型資料夾一樣分批載入。
  • 修改或刪除：右鍵按左側項目，或使用清單上方的編輯…與刪除智慧型資料夾；工具列也會說明搜尋條件。

智慧型資料夾本身不存項目。刪除只移除儲存的搜尋條件，也不能把項目搬進去；項目符合條件時才顯示，重新命名、搬移或修改後不符就離開。和標籤相同，智慧型資料夾只屬於你，其他人看不到。它永遠只列出你當下可開啟的項目；失去資料夾或空間權限後，相關項目會消失，以無權開啟資料夾為範圍的智慧型資料夾會列出空白。資料保存在資料庫：備份 data 資料夾會保留，檔案備份不會。

詳細資料

按工具列詳細資料窗格或 Alt + Enter，開啟右側窗格，顯示所選項目；未選取時顯示目前資料夾。

  • 大小與包含：資料夾計算所有層級內容的大小與檔案／資料夾數，不含資源回收筒。大型資料夾可能需要一些時間。
  • 選取多個項目時，顯示合計檔案與資料夾數（含所選資料夾內的項目）與總大小。
  • 標籤：依名稱列出你的標籤，可用編輯標籤修改（參閱標籤）。
  • 活動：誰在何時上傳、編輯、重新命名、搬移、複製、刪除或還原。資料夾包含目前裡面所有項目的活動（含資源回收筒項目）；空間根目錄則涵蓋整個空間。只顯示最近 50 筆。

有權開啟項目的人都能查看活動。分享與權限變更（誰取得權限、分享連結）只有空間管理者與擁有者可見。完整紀錄、篩選與匯出仍在活動紀錄。

名稱已被使用時

上傳、搬移、複製、貼上或從資源回收筒還原前，ThirtyFile 會檢查目標是否有同名項目（不區分大小寫，伺服器上的資料夾除外）。每個衝突都顯示雙方大小與日期，並詢問：

  • 取代：上傳檔案會將內容寫入既有檔案，保留其分享、權限與我的最愛，原內容保存為先前版本。搬移、複製或還原時，原項目會移到資源回收筒，仍可救回。之後若搬移或複製到伺服器上的資料夾（或從中搬出）失敗，原項目會從資源回收筒回到原處。
  • 略過：不處理此項目。
  • 保留兩者：新項目加上編號，例如 Report (1).docx。上傳清單會顯示儲存名稱。

勾選將此選擇套用到接下來的衝突，可對剩餘衝突使用相同答案；或選取消停止，不變更任何內容。同名的上傳資料夾會合併到既有資料夾：取代會取代內部同名檔案，保留兩者保留兩份。把副本貼回自己的資料夾時，和 Windows 一樣總會加上編號。

上傳完成前，若目標資料夾刪除或你失去新增檔案權限，上傳會失敗並在清單提示原因，不會把檔案存到其他地方。

先前版本

在線上編輯器儲存、以上傳取代或還原先前版本時，原本內容會保存為先前版本。選取檔案並開啟詳細資料窗格（Alt + Enter），版本會由新到舊列出作者與時間。開啟在新瀏覽器分頁檢視，下載儲存該版本，還原將其作為目前內容；還原前內容也會成為版本，因此可用相同方式復原還原。

  • 預設每個檔案保留最新 20 個版本，每個保留 90 天。管理員可在控制台 › 一般修改兩項限制或關閉版本功能。
  • 先前版本不計入空間配額；管理員可在控制台 › 儲存用量查看占用量。
  • 重新命名或搬移（含跨空間）會保留版本；副本從沒有版本開始。永久刪除檔案也會刪除版本。
  • 有權開啟檔案的人都能查看與下載版本，還原需有編輯權限。

Mac 風格

Mac 風格（參閱介面風格）讓檔案瀏覽器採用 Finder 版面與按鍵。檔案、可用操作與確認問題和 Windows 風格相同：同名衝突仍會出現名稱已被使用時的對話方塊，永久刪除總會先確認。

  • 側欄：與 Windows 風格左側選單相同位置，以群組放在內縮、半透明圓角面板。我的最愛包含所有我的最愛、最愛資料夾與智慧型資料夾（標題旁 + 可新增）。接著是空間、分享（與我共用、我的分享連結）、最近使用、資源回收筒與標籤。按標題可隱藏／顯示群組，項目與檔案可拖放到裡面的資料夾或空間。
  • 工具列：返回／前進、目前資料夾名稱、檢視（圖示、清單、直欄、圖庫）、排序依據、分組依據、分享、標籤，以及提供其餘功能的操作（⋯）：新增資料夾、上傳、快速查看、取得資訊、重新命名、複製、貼上、搬移到這裡、移到資源回收筒、我的最愛、標籤、前往資料夾…與快捷鍵。搜尋框在右側，導覽與命令使用圓角膠囊。窄視窗的檢視按鈕改為選單，排序、分組、分享與標籤保留在操作中，工具列維持單行。直欄與圖庫不提供分組。
  • 路徑列與狀態列：預設隱藏。開啟檢視選項（檢視按鈕旁箭頭，窄視窗則為檢視），開啟顯示路徑列或顯示狀態列。選項依帳號在此瀏覽器保存，不會跟隨到其他瀏覽器。狀態列保留項目數與儲存用量，路徑列位於視窗底部，顯示目前資料夾路徑。按其中資料夾可前往，拖放項目可搬移到該處。沒有直接輸入路徑的方框；前往資料夾（⌘ + Shift + G）會要求輸入，詳見路徑。
  • 分頁：開啟兩個以上分頁才顯示分頁列。即使隱藏，仍可在新分頁開啟資料夾與使用分頁快捷鍵。
  • 清單：緊湊交錯底色列，有縮圖時顯示小縮圖。預設欄為名稱、修改日期、大小與種類，日期使用介面語言的完整格式。上傳者等欄位可從檢視選項 → 欄位開啟；欄位選擇與寬度和另一風格分開保存。資料夾名稱旁有三角形，按它或 → 可直接在下方縮排展開；← 或再次按一下收合。這種大型資料夾會和一般大型資料夾一樣，隨捲動分批載入。
  • 圖庫：上方大型預覽與開啟檔案相同（圖片、影片、PDF、Office 與文字，其他類型顯示圖示），下方縮圖列。開啟資料夾時先選第一項。→／←前往下一／上一項，Home／End到第一／最後一項，Space開啟快速查看；縮圖列跟隨捲動，大型資料夾分批載入。停留在項目後才載入預覽，影片不會自動播放。右側面板顯示類型、大小、日期與標籤，並提供開啟、下載、分享、重新命名、移到資源回收筒；縮圖列末端按鈕可顯示／隱藏面板（此瀏覽器會記住）。選取、複製、搬移、拖到資料夾與右鍵選單和其他檢視相同；Enter可在預覽上方名稱處重新命名。此檢視不支援分組依據，手機也不提供。
  • 快速查看：按 Space在清單上方視窗預覽所選項目，內容和開啟檔案相同。方向鍵切換上一／下一項，清單選取也跟著變更；選取多項時只依序預覽它們。Space 或 Esc關閉，開啟則正式開啟項目。
  • 搬移：沒有剪下。先複製（⌘ + C），到目標資料夾後選搬移到這裡（⌘ + Option + V）搬移，或用貼上（⌘ + V）建立副本。拖曳與 Windows 風格相同。
  • 新增項目立即進入排序後的正確位置；按已選名稱不會重新命名，請按 Enter。
  • 外觀：資料夾與檔案使用專屬圖示（文件頁面顯示格式名稱或符號）、強調色圓角選取、半透明側欄與低調工具列按鈕，明暗模式都適用。
  • 手機上的 Mac 風格和 Windows 風格的版面、選單和按鍵相同，但保有自己的外觀和圖示。

按鍵和 Finder 相同，但瀏覽器保留的按鍵除外（如 ⌘ + N、⌘ + W）。非 Mac 電腦使用 Ctrl 代替 ⌘，Alt 代替 Option。其他按鍵與上方 Windows 風格相同：清單移動、⌘ + A、⌘ + Z、Shift + F10、F5、輸入名稱開頭、Esc、?。

資源回收筒

刪除項目會進入資源回收筒，可從中還原。30 天後永久移除（管理員可用THIRTYFILE_TRASH_DAYS修改，或保留到清空），手動清空也會永久移除。頁面顯示實際保留天數。

資源回收筒列出所有你可開啟空間的刪除項目。清空資源回收筒只刪除你管理的空間（自己的檔案、你為管理者的團隊空間），會先列出各空間與刪除數量供確認。只有檢視權限的空間項目會留下。

永久刪除大型資料夾或清空大量回收筒可能需要時間。項目立即從回收筒消失，底部訊息顯示刪除進度，關閉頁面仍繼續。將數千項資料夾移到回收筒、還原，或在伺服器資料夾重新命名，也需要片刻。完成前該資料夾無法還原、搬移或複製，會提示稍後再試。

較寬螢幕的刪除者欄顯示移到回收筒的人。早於紀錄功能刪除或帳號已移除的顯示橫線。清單上方由我刪除只看自己的操作，所有人刪除恢復完整清單。

手機操作

同一網站也可用於手機。點項目開啟，其餘使用清單上方按鈕。

  • 選取：長按項目片刻以選取，之後點按可加入／移出選取。平板也會開啟所選項目選單。
  • 操作所選項目：選取時，底部工具列提供下載、分享、搬移、刪除與更多（剪下、複製、重新命名等）。×清除選取。清單上方保留導覽窗格（空間與資料夾樹）、新增、排序、檢視、···與詳細資料窗格，有內容可貼上時也有貼上。
  • 核取方塊：開啟檢視 › 項目核取方塊，每種檢視的項目都會顯示核取方塊。
  • 上傳：選新增 › 上傳檔案或上傳資料夾。
  • 位址列：長路徑顯示末端，也就是目前資料夾；滑動可查看上層路徑。
  • 主畫面：把網站加入主畫面（Safari：分享 › 加入主畫面；Chrome：加入主畫面或安裝應用程式），之後會像應用程式開啟，不顯示瀏覽器工具列，使用網站名稱與標誌。
