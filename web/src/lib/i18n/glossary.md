# Glossary

The words ThirtyFile uses in each language, for the interface (the dictionaries in this folder), the server's texts and
the website (`site/zh-TW/`, `site/zh-CN/`, `site/ja/`). A term that appears here is written the same way everywhere.
When a translation needs a new recurring term, add it here in the same pull request.

## Style

|                             | Traditional Chinese (`zh-TW`)                                 | Simplified Chinese (`zh-CN`)                                                  | Japanese (`ja`)                                                                                   |
| --------------------------- | ------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Words                       | Taiwan usage                                                  | Mainland usage, translated rather than converted from `zh-TW` (see the table) | The terms of Windows Explorer and Finder where they exist                                         |
| Tone                        | 你, plain and friendly                                        | 你, plain and friendly                                                        | です・ます in sentences; short plain forms on buttons, menu items and headings (保存, 名前の変更) |
| Punctuation                 | Full-width: ，。、：；？！（）「」                            | Full-width: ，。、：；？！（）“”                                              | 。、 and full-width （）「」; no full stop on buttons and labels                                  |
| Latin text and numbers      | A space between them and Chinese: `Docker 映像檔`, `200 個字` | A space between them and Chinese: `Docker 镜像`, `200 个字`                   | A space between them and Japanese: `Docker イメージ`, `200 文字`                                  |
| Words written in katakana   |                                                               |                                                                               | Compounds without spaces: ネットワークドライブ, コントロールパネル                                |
| Code, commands, paths, keys | Unchanged, in `code`                                          | Unchanged, in `code`                                                          | Unchanged, in `code`                                                                              |

Names stay as they are in every language: ThirtyFile, WebDAV, S3, SFTP, FTP, OpenID Connect, Docker, Docker Compose,
GitHub, Microsoft, Google, Keycloak, Authentik, Excel, Word, PowerPoint, NAS.
